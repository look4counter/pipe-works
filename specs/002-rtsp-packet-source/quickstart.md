# 검증 안내: RTSP 비디오 패킷 수신

**후속 변경**: 현재 종료 검증은 [003 검증 안내](../003-step-yaml-config/quickstart.md)를 따른다.

1. 모의 PyAV 연결이 첫 비디오 스트림과 크기가 있는 패킷 두 개, 빈 패킷 하나를 제공하게 한다.
2. `RTSPSource(url).process(iter(()))`를 반복해 두 패킷이 순서대로 나오고 원본 객체를 보존하는지 확인한다.
3. 첫 연결이 오류를 내게 하고 재시도 후 두 번째 연결의 패킷이 나오는지 확인한다.
4. 재연결 비활성화와 반복자 닫힘 각각에 대해 현재 연결 정리와 추가 연결 중단을 확인한다.
5. 재연결을 끈 상태의 연결 오류와 스트림 종료가 `Pipeline.run()`을 오류로 끝내는지 확인한다.
