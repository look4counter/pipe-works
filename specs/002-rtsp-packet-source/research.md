# 설계 검토: RTSP 비디오 패킷 수신

**후속 변경**: 현재 생성자와 종료 방식은 [003 설계 검토](../003-step-yaml-config/research.md)를 따른다.

## 결정

- 참고 코드와 현재 단계 계약을 결합한다. 소스는 입력 반복자를 사용하지 않고 패킷 컨텍스트를 생성한다.
- 재연결 간격은 3초, 연결과 읽기 제한 시간은 각각 5초를 사용한다.
- 패킷 데이터는 복사하지 않는다. 다음 단계에서 원본 패킷과 스트림 정보를 사용할 수 있게 보존한다.
- 기존 예제의 `RTSPSource(url)` 호출을 유지하면서 재연결 여부와 전송 방식은 단계 설정에서 받는다.

## 범위 밖

- 디코딩, 인코딩, 발행, 통계 집계, 설정 파일 해석은 이번 변경에 포함하지 않는다.
