# 배경 분기 계약

TapSkipIfBusy의 주 출력은 원본 컨텍스트다. 배경 입력은 수락 시점의 필드를 가진 별도 컨텍스트로서 최상위 속성 변경과 핫스왑 epoch를 격리한다. 별도 결과는 주 경로에 병합하지 않는다.
영상·GPU 버퍼·중첩 사전과 네이티브 자원 소유자는 참조를 공유한다. 공유 값의 제자리 수정은 격리하지 않으므로 배경 Step은 읽기 전용으로 사용한다.
분기 이전의 상류 핫스왑 정보는 보존한다. 같은 파일을 감시하는 여러 Step의 파일 변경 적용은 유지한다. 바쁨 상태의 생략과 정상·조기 종료 동작은 기존과 같다.
