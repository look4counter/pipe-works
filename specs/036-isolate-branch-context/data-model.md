# 데이터 모델

- 주 컨텍스트: 기존 PipelineContext 인스턴스. 분기 전후 동일성을 유지한다.
- 배경 컨텍스트: 수락 시 vars(item)의 필드를 전달받는 별도 PipelineContext. 최상위 속성 추가·삭제·재할당을 격리한다.
- epoch: 분기 시점의 불변 튜플을 공유하되 각 경로가 자신의 컨텍스트 속성을 재할당한다. 공통 상류 변경은 양쪽에서 유지한다.
- 자원 참조: frame·packet·cuda_stream·video_stream·_decode_buffer 및 중첩 데이터는 공유한다. 배경 작업은 공유 데이터 자체를 읽기 전용으로 사용한다.
- 슬롯: 유휴 → 별도 컨텍스트 수락 → 처리 중 → 다음 입력 요청 시 유휴. 바쁨·닫힘 상태에서는 입력 객체를 만들거나 큐에 추가하지 않는다.
