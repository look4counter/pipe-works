# 데이터 모델

요청은 원본 소유 컨텍스트, 속성 사전만 분리한 작업 컨텍스트, 입력 텐서 참조·준비 이벤트, 공통 기한, 소비·완료·만료 상태와 결과를 가진다. 복사본·복사 스트림·미완료 복사 목록은 존재하지 않는다.

전체 입력 신호 release_requested·release_event는 단일 Step에서 적용한다. 영상 신호 frame_release_requested·frame_release_event는 단일·복수 Step에서 적용한다. 이벤트 없는 신호는 이미 완료된 읽기를 뜻한다. 이벤트가 있으면 query가 참이어야 전달한다. 요청의 done은 작업자 처리가 종료됐음을 뜻하고 input_drained는 GPU 정리가 성공했음을 뜻한다. 정리 실패만으로 원본 전달을 허용하지 않는다.

영상 신호는 이후 내부 단계가 원본을 다시 사용하지 않는다는 약속이다. 전처리에서 생성한 독립 model_input은 추론에서 계속 사용할 수 있다. 다른 공유 데이터는 읽기 전용이다. 폐기된 원본 참조도 작업 완료까지 보관한다.

슬롯은 요청 하나·닫힘 상태·조건 변수를 가진다. 각 단계의 입력 슬롯과 출력 반복자는 요청 사이에 유지한다. 콜백은 요청에 귀속되며 오래된 문맥은 다른 요청을 해제하지 못한다.
