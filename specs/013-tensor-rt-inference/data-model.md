# 추론 데이터 모델

## 영상별 실행 옵션 갱신

Step 상태는 gpu_id·inference_interval_frame·profile_index다. 모델 설정은 plugins·max_batch_size·timeout_ms다. 공유 요청은 profile_index를 보관하고 호환 키에 GPU·프로파일·입력 이름·자료형·비배치 형상을 포함한다. 세션은 (GPU, 프로파일)별로 보관한다. 이 정의는 이전 모델 공통 프로파일 정의를 대체한다.

## 모델 실행 옵션

모델 설정은 profile_index(기본 0인 음수가 아닌 정수)와 plugins(기본 빈 경로 문자열 목록)를 포함한다. 상대 경로는 모델 YAML 디렉터리 기준이다. 세션은 번호와 선택 완료 상태를 보관하며 최초 추론에서 실행 스트림에 프로파일을 적용한다. 공유 작업자는 모델별 설정을 읽고 GPU별 세션에 동일한 번호와 플러그인을 전달한다.

- 입력: `model_input`의 CUDA 텐서 또는 실제 입력 이름별 CUDA 텐서 사전. 자료형·차원·GPU는 엔진과 일치해야 한다.
- 출력: `model_output`은 실제 출력 이름별 CUDA 텐서 사전 또는 None. 전처리·후처리 없이 원시 값과 형상을 보존한다.
- 요청: GPU 연속 복제 사전, 생산자 준비 이벤트, 원본 소유자, GPU 번호, 제출 시각, 실행 문맥, 완료·폐기 표시 및 결과.
- 실행기: TensorRT Logger·Runtime·엔진·컨텍스트·플러그인 핸들, 바인딩 메타데이터 및 출력 할당기.
- 출력 할당기: 자료형·GPU·형상·바이트 크기·정렬된 버퍼와 출력 strides. 실행 완료까지 버퍼를 소유한다.
- 상태: 선택 → 슬롯 확보 → GPU 복제 → 비동기 실행 → 제한 시간 안 반환 또는 결과 폐기. 사용 중과 실패는 입력을 그대로 전달한다.
# 프레임 간격 설정 갱신

`TensorRTInference.inference_interval_frame`은 기본값 1인 양의 정수이며 불리언은 제외한다. 개별·배치 입력 인덱스 0부터 나머지가 0일 때 추론한다. 그 외 입력은 같은 컨텍스트를 `model_output=None`으로 전달한다. 이전 키 검증 실패는 기존 GPU 번호와 간격을 보존한다. 기존 데이터 설명의 간격 이름은 이 계약으로 대체한다.
