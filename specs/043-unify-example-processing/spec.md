# 기능 명세: 예제 전후처리 통일

작성일: 2026-10-17
상태: 검증 완료

## 사용자 시나리오와 검증

### 사용자 이야기 1 — YOLO 전후처리 재사용 (우선순위: P1)
개발자는 TensorRT 추론에서도 YoloPreProcess와 YoloPostProcess를 사용한다.
인수 조건: 예제의 TensorRT 전용 전후처리 파일 두 개가 삭제되고 실행 경로는 YOLO 전후처리로 연결된다.

## 요구사항

- FR-001: examples/step/tensor_rt_pre_process.py와 tensor_rt_post_process.py를 삭제한다.
- FR-002: 현재 예제·테스트·도구·문서의 사용을 YoloPreProcess·YoloPostProcess로 전환한다.
- FR-003: GPU 입출력·탐지·원본 프레임 해제·실제 추론 백엔드별 보고 계약을 유지한다.
- FR-004: 삭제된 클래스에 대한 실행 코드의 특별 처리는 정리한다. 벤치마크의 과거 Git 기준 구현 조회는 유지할 수 있다.

## 성공 기준

- SC-001: 삭제 대상이 없고 현재 모듈에 대한 가져오기 참조가 없다.
- SC-002: 전후처리·TensorRT·비동기 보고·원격 전달 회귀 검사가 통과한다.
- SC-003: 벤치마크는 현재 YOLO 구현을 사용하고 과거 기준 구현 비교를 지원한다.

## 경계 조건과 가정

TensorRT 추론 backend는 유지한다. 전후처리 구현을 새로 만들거나 별칭 모듈을 남기지 않는다. 실제 추론 전 단계의 일반 YOLO 보고와 실제 추론 이후 백엔드 보고를 구분한다.

## 명확화 검토

사용자가 삭제 파일과 대체 구현을 지정했다. 범위·오류·의존성·완료 조건에 중대한 불명확성이 없으며 질문은 0건이다. 헌법은 미작성 템플릿이다.

## 추가 요청: 사용하지 않는 DB 예제 삭제

### 사용자 이야기 2 — 불필요한 DB 예제 정리 (우선순위: P1)
개발자는 사용하지 않는 metadata_from_db.py와 save_inference_result_to_db.py를 예제에서 제거한다.
인수 조건: 두 예제 파일과 삭제한 MetadataFromDB의 전용 테스트가 없으며 현재 코드에서 참조하지 않는다.

- FR-005: examples/step/metadata_from_db.py와 save_inference_result_to_db.py를 삭제한다.
- FR-006: 삭제한 예제만 검증하는 tests/test_metadata_from_db.py를 제거한다. 다른 기능과 기존 변경은 유지한다.
- SC-004: 현재 소스·예제·테스트·문서·도구에서 두 예제를 참조하지 않으며 남은 예제의 구문과 관련 가져오기 검증이 통과한다.

명확화 검토: 삭제 대상이 명시되었고 파이프라인에서 사용하지 않는다. 추가 질문은 없으며 기존 헌법·규칙 검토 결과는 동일하다.
