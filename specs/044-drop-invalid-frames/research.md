# 조사 결과

- 결정: 크기 검사 예외를 전용 타입으로 구분해 프레임 반복문에서 처리한다.
- 근거: 전체 ValueError를 잡으면 설정과 장치 오류까지 숨긴다.
- 대안: 전체 오류 복구 활성화는 범위를 벗어나며 불완전한 입력을 전달할 수 있어 제외했다.
- 결정: 기존 `_DroppedFrame`과 `_frame_drop_scope`를 재사용한다.
- 근거: EveryNFrames와 CudaAsync는 입력당 출력 하나 계약이 있으므로 단순 출력 생략으로는 안전한 폐기가 안 된다.
- 대안: 반복자를 매번 재생성하거나 전역 프로세스를 재시작하는 방식은 정상 상태를 불필요하게 잃어 제외했다.
- 미해결 사항: 없음. 새로운 기술이나 의존성이 필요하지 않다.
