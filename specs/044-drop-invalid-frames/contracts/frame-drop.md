# 프레임 폐기 호출 규약

- YoloPreProcess와 BoxOverlay는 크기 오류를 발견한 입력을 다음 단계로 전달하지 않는다.
- 일반 반복자 호출에서는 출력을 생략한다.
- 프레임 폐기 범위 안에서는 입력당 출력 하나 계약을 만족하도록 `_DroppedFrame`을 반환한다.
- CudaAsync의 후속 내부 단계는 폐기 신호를 처리하지 않으며, 외부에서는 신호를 소비하거나 상위 폐기 범위로 전달한다.
- EveryNFrames는 기존 규약대로 폐기 신호를 소비한다.
- 크기 외 오류와 시간 초과의 기존 정책은 바꾸지 않는다.
- 직접 호출하는 저수준 NV12 변환 함수는 잘못된 입력에 대해 계속 예외를 발생시킨다.
