# 구현 계획: 소스 주석 한글화

## 요약과 기술 맥락
Python 3.11.9 SDK의 설명만 번역한다. 의존성 추가와 실행 인터페이스 변경은 없다. Windows 환경에서 Python 표준 라이브러리의 ast와 tokenize로 검증한다.

## 규칙 검토
헌법은 미작성 템플릿이므로 적용할 구체 원칙이 없다. AGENTS.md의 한글 문서 및 speckit 절차를 적용한다. 설계 후에도 위반은 없다.

## 구조와 단계
대상은 src/, examples/, tests/, tools/의 Python 파일 및 build.ps1의 설명이다. 외부 생성 도구는 제외한다.
1. 영어 설명 목록과 번역 전 구문을 확보한다.
2. 설명 주석과 docstring을 의미에 맞게 번역한다.
3. 도구 지시문, 일반 문자열 및 실행 구문 보존을 확인한다.
4. 전체 검색으로 누락을 검토하고 명세와 실제 결과를 대조한다.

## 검증 전략
새 테스트는 작성하지 않는다. 모든 대상 Python 파일의 구문을 분석하고 docstring만 제거한 AST를 변경 전후 비교한다. 문자열 내 코드 주석도 검색한다. GPU 실행은 이 변경의 검증에 필요하지 않다.

## 추가 설명 설계

대상은 src/pipeworks/pipeline.py의 _LiveConfig만이다. 필드의 의미, 첫 조회 허용, 단조 시계와 0.5초 확인 간격, 파일 구독의 지연 활성화, 잠금의 역할, 해시를 통한 중복 처리 방지, 검증 실패 시 기존 설정 유지 및 SimpleNamespace 변환을 설명한다. 주석만 추가하고 AST 전체 비교로 동작 보존을 확인한다. 새로운 설계나 의존성은 없으며 규칙 검토 결과는 동일하다.
