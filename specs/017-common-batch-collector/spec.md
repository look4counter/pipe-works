# 공통 배치 수집기 분리

- FR-001: local_yolo의 요청 수집·호환 키 비교·최대 크기·수집 기한·비호환 요청 보류를 모델 독립 모듈로 분리한다. 기존 YOLO 수집 정책은 유지한다.
- FR-002: YOLO 요청·결과 이벤트·GPU 처리·모델 설정은 local_yolo에 유지한다. 이번에는 TensorRT 배치나 새로운 종료 정책을 추가하지 않는다.
- SC-001: 최대 크기·수집 기한·다른 옵션 보류와 기존 실제 GPU 배치 회귀가 통과한다.

명확화: 이번 요청은 수집기만 분리한다. 공통 수집기는 호환 키와 요청 수신 시각을 받아 묶음을 반환한다. 결과 전달과 모델 작업자는 이번 범위에서 기존 구현에 남긴다. 추가 질문은 필요하지 않다.
