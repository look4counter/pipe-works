# 공통 수집기

pipeworks.batch_collector.collect_batch는 큐·보류 큐·최대 크기·초 단위 수집 시간을 받는다. 호출자는 호환 조건 key와 수신 시각 received_at 함수를 제공한다. 반환값은 호환 요청 목록이다. 모델·GPU·결과 전달은 호출자가 관리한다.

local_yolo는 기존 클래스·신뢰도·GPU 옵션을 호환 키로 전달한다. 오래된 요청의 수신 시각 기준 기한과 다른 옵션의 보류 순서를 유지한다. 이번에는 작업자 종료·결과 이벤트·TensorRT 배치를 변경하지 않았다.

명세·명확화·계획의 일관성을 분석했고 차단 충돌이 없었다. 공유 작업자와 기존 YOLO 배치 회귀를 확인하고 수렴 점검에서 추가 구현 차이가 없음을 확인했다.
