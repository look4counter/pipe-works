# 구현 계획: 실행별 프레임 처리 보고

## 남은 이름 정리 (2026-10-04)

보고 구현 모듈을 `stream_report.py`로 옮기고 모든 내부 import와 테스트 import를 변경한다. 현재 기능 명세 디렉터리를 `010-stream-report`로 바꾸고 다른 명세의 링크와 요구사항을 현재 공개 단계에 맞춘다. 폐기한 이름의 문서 언급도 제거한다. 변경 뒤 관련 테스트와 전체 테스트를 실행해 보고 기능과 중앙 프로세스 전달을 확인한다.

## 단일 보고 단계 정리 (2026-10-04)

사용자 요청에 따라 구형 보고 클래스와 `embedded` 공개 내보내기를 제거한다. 수집기 및 기록 함수는 `StreamReport`와 다른 단계가 계속 사용하므로 유지한다. `tests/test_report.py`의 구형 단계 전용 사례는 제거하고, 컨텍스트 동일성 및 두 줄 출력 등 유효한 계약은 `StreamReport` 사례로 검증한다. 예제는 이미 `StreamReport`를 사용하므로 그대로 둔다.

## 추론 시간 명확화 (2026-10-04)

`local_yolo.py`의 공유 작업자가 배치 준비를 마친 뒤 `model.predict` 직전에 시간을 재고, GPU 완료 이벤트를 기다린 직후 구간을 닫는다. 측정값을 요청 객체에 보관하고 `infer`의 선택적 콜백으로 해당 파이프라인의 통계 수집기에 전달한다. 기존 반환값은 유지한다. `YoloDetectBatch`는 호출 전체의 벽시계 시간 기록을 제거한다. `YoloDetect`도 모델 로드와 이미지 복사 이후 예측 호출만 측정한다. 관련 단위 테스트에서 대기 시간 제외, 배치별 기록 및 반환값 호환을 확인한다.

## 현재 구성

`NvidiaDecode`가 프레임 시작 시각을 넣고 `NvidiaEncode`가 완료 프레임과 인코딩 시간을 기록한다. `YoloDetect`와 `YoloDetectBatch`는 공통 추론 시간을 기록한다. `YoloDetectBatch`와 `RTSPPublish`도 단계별 시간을 기록한다.

`Pipeline._run_local`은 실행마다 `report_scope()`를 열어 통계를 분리한다. 수집기는 잠금으로 보호하고 `StreamReport`가 약 1초마다 읽어 초기화한다. 독립 Step 호출에는 기본 수집기를 사용한다.

## 출력과 검증

`StreamReport`는 첫 줄에 수신·송신 상태와 FPS·프레임 평균·추론 평균을, 둘째 줄에 실제 기록된 단계의 평균을 출력한다. 전달받은 패킷 컨텍스트는 변경하지 않는다. `tests/test_report.py`와 중앙 프로세스 테스트에서 통계 분리, 출력, 전달을 검증한다.

## 마지막 단계 상태 보고 계획

1. 수집기에 수신·송신별 마지막 성공 시각과 마지막 실패 시각을 추가한다. `RTSPSource`는 유효 비디오 패킷을 내보낼 때와 연결·수신 실패 때, `RTSPPublish`는 패킷 송신 완료와 연결·송신 실패 때 기록한다.
2. `StreamReport`는 마지막 Step으로 상류 반복자를 소비한다. `RTSPPublish`가 출력을 내지 않아도 별도 보고 작업자가 1초마다 실행별 수집기를 읽어 출력한다.
3. 보고 작업자는 실행 문맥의 통계 수집기와 호출자 표준 출력 대상을 이어받는다. 종료 신호를 받으면 즉시 끝내고 다른 파이프라인과 출력을 섞지 않는다.
4. 기존 FPS·평균 처리·추론·단계별 평균 계산을 공유한다. 첫 프레임 전에도 0 FPS와 수신·송신 대기를 표시한다. 최근 성공 5초 초과와 명시적 오류를 구분한다.
5. 01·02 RTSP 예제에서는 `RTSPPublish` 뒤에 `StreamReport`를 둔다.

## 추가 검증

- 출력 없는 상류를 소비하는 동안 주기 보고가 계속되는지, 종료 뒤 작업자가 멈추는지 테스트한다.
- 수신·송신 성공, 오류, 시간 경과 상태와 동시 파이프라인 분리를 검증한다.
- 중앙 프로세스에서 보고 문구가 호출자 콘솔에 전달되는지 확인한다.
## 최근 10초 계획

_ReportStats에 프레임·추론별 완료 시각과 처리 시간 deque를 보관하고 기록 및 출력 시 만료 표본을 제거한다. 기존 1초 합계는 유지하고 _take_report에 최근10초 평균 두 항목을 추가한다. 표본 없는 값은 None으로 반환하고 출력 이름을 명확히 구분한다. tests의 기존 보고 검증 기대를 갱신하고 결정적 시계 모의로 가중 평균과 경계·격리를 확인한다. 공통 lock으로 작업자 기록과 보고를 보호한다.
## 표기 후속 계획

StreamReport.report_once의 문자열만 바꾸고 평균 계산은 유지한다. 프레임과 추론 각각 두 값을 하나의 출력 항목으로 묶으며 추론 건수는 항목 끝에 유지한다. tests/test_report.py의 기대 문자열과 검증 기록을 갱신한다.
