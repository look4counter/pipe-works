# 계약: 스트림 통계 기록과 읽기 전용 보고

기존 `record_frame`, `record_inference`, `record_stage`, `record_receive`, `record_publish`의 호출 인자를 유지한다. 실행 범위별 수집기와 독립 호출의 기본 수집기도 유지한다.

`StreamReport.process()`는 입력 객체·순서를 보존하며 입력 중단 시에도 약 1초마다 기존 두 줄 형식으로 출력한다. 보고자의 시작과 조회는 수집기 잠금을 획득하거나 누적값·이력을 수정하지 않는다. 기록자끼리의 갱신 잠금과 출력·IPC 내부 동기화는 유지한다.

1초 값은 출력 간 실제 시간 구간의 누적값 차분이다. 최근 10초 값은 정확한 (현재-10초, 현재] 범위의 완료 표본 가중 평균이다. 표본이 없으면 기존처럼 없음으로 표시한다. 서로 다른 보고자의 조회는 통계를 소모하지 않는다. 두 보고자가 같은 구간을 관측하면 같은 수치를 얻는다.
