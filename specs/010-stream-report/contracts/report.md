# 계약: 스트림 통계 기록과 읽기 전용 보고

기존 `record_frame`, `record_inference`, `record_stage`, `record_receive`, `record_publish`의 호출 인자를 유지한다. 실행 범위별 수집기와 독립 호출의 기본 수집기도 유지한다.

`StreamReport.process()`는 입력 객체·순서를 보존하며 입력 중단 시에도 약 1초마다 기존 두 줄 형식으로 출력한다. 보고자의 시작과 조회는 수집기 잠금을 획득하거나 누적값·이력을 수정하지 않는다. 기록자끼리의 갱신 잠금과 출력·IPC 내부 동기화는 유지한다.

1초 값은 보고자가 관측한 발행본 사이 누적값 차분이며 FPS는 발행 시각 차이로 나눈다. 최근 10초 값은 발행된 표본 중 정확한 (현재-10초, 현재] 범위의 가중 평균이다. 최신 기록의 발행 지연은 약 100ms이며 스케줄링 지연이 추가될 수 있다. 표본이 없으면 기존처럼 없음으로 표시한다. 서로 다른 보고자의 조회는 통계를 소모하지 않는다. 같은 발행본과 구간을 관측하면 같은 수치를 얻는다.

리포트 없는 파이프라인은 공통 기록을 건너뛰며 명시적 report_scope(enabled=True)는 직접 수집을 허용한다. 공용 발행 작업자는 활성 보고자가 있을 때만 실행하고 마지막 종료에서 정리한다. 보고·읽기 잠금은 없지만 기록자와 발행자는 기존 수집기 잠금을 사용한다.
