# 최근 송신 PTS 계약

내부 함수 record_publish(success, *, pts=None, time_base=None)는 기존 호출과 호환된다. 성공하면 PTS와 시간 기준을 같이 갱신하고 실패하면 최근 성공 값을 유지한다. 비활성 수집에서는 잠금·시계 측정 전에 반환한다.

StreamReport는 발행된 최근 성공 송신의 PTS를 첫 줄에 표시한다. 0과 음수는 정수 그대로 출력하며 값이 없으면 없음이다. 시간 기준이 있으면 time_base=분자/분모를 함께 표시한다. 실제 mux가 사용하는 출력 시간 단위로 환산하기 전 입력 패킷의 시각을 표시한다.

통계는 파이프라인 실행마다 분리한다. 네이티브 패킷과 GPU 프레임은 보관하지 않으며 보고 단계는 수집기 잠금을 획득하지 않는다. 송신 실패나 무입력 중에도 최근 성공 PTS는 남아 있고 기존 송신 상태 항목으로 현재 상태를 구분한다.
