# 데이터 모델

## 파이프라인 실행 모드

- development: 기본 False인 bool. 생성자에서 검증하고 인스턴스에 저장한다.
- False는 운영, True는 개발 그룹에 대응한다. Pipeline 직렬화에 포함된다.
- 공개 run에는 그룹 선택 인자가 없다.

## 내부 중앙 그룹

- server_group: 기본 production인 대소문자 구분 문자열.
- 허용값: 영문자·숫자·밑줄·하이픈 1~64자.
- 같은 설치·사용자·그룹의 요청은 같은 서버를 사용한다.
- 연결 주소와 시작 잠금은 동일한 그룹 식별자를 사용한다.

## 실행 상태

미시작 → 시작 잠금 확보 → 서버 시작 → 연결 → 실행 → 마지막 연결 종료 → 유휴 종료.
상태 전이는 그룹별이다. 개발 서버 종료 시 운영 그룹의 연결·작업자·유휴 타이머를 변경하지 않는다.
