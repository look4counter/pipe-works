# 조사 결과

## 결정: 생성자에 실행 모드 저장

근거: 사용자가 Pipeline 생성자의 development 불리언을 명시적으로 요청했다. 모드는 Pipeline에 저장하고 run_remote가 내부 그룹으로 매핑한다. 전역 환경변수를 변경하지 않아 동시 운영·개발 호출을 유지한다.
대안: run의 server_group과 임의 그룹 선택은 새 사용자 계약에 따라 제거한다.

## 결정: 연결 주소와 시작 잠금을 함께 분리

근거: 주소는 설치 경로·Windows SID·프로토콜에 묶인다. 기본 그룹은 기존 경로를 유지하고 다른 그룹만 이름의 전체 SHA-256 해시를 추가한다. 서버에는 명령행 인자로 그룹을 전달한다.
대안: 주소만 분리하면 시작 잠금을 공유하고, 전역 주소 변경은 동시 요청에 간섭한다.

## 결정: 실제 Windows 프로세스로 검증

근거: 모의 객체만으로는 연결, 자동 시작, PID 분리, 종료 독립성을 확인할 수 없다. 테스트용 개발 그룹만 강제 종료하고 운영 요청 지속을 확인한다.
대안: 실제 GPU 장애 주입은 장치 전체에 영향을 줄 수 있어 사용하지 않는다.
