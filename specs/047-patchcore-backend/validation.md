## 구현 전 분석

명세·계획·작업의 중대한 충돌, 중복, 누락 없음.
FR-001/002/003/005/006은 T002·T003, FR-004는 T004·T005,
SC-001/002/003은 T002·T005로 연결된다. 품질 체크리스트 8/8 통과.
헌법은 미작성 템플릿으로 원칙 검사는 제외했다.
확장 훅 설정 파일은 없으며 분기 생성 없이 현재 작업 공간에서 진행했다.

## 실행 결과

- 신규 테스트: 11개 통과. 실제 CUDA에서 실행했으며 건너뛴 테스트 없음.
- 학습 프로젝트의 실제 저장 함수를 사용한 체크포인트로 점수·맵 일치 확인.
- 청크 경계를 넘는 576개 패치·1025개 메모리의 결과를 전체 거리 계산과 비교.
- GPU 감시, 입력·체크포인트 오류, 단일 Step과 공유 배치 요청 분리 검증.
- 공유 배치는 두 요청이 실제 한 번의 배치 크기 2 추론으로 결합됐는지도 확인.
- 기존 회귀: 61개 중 60개 통과, 기존 실패 1개.
- 신규 코드의 ruff 검사 및 git diff --check 통과.

회귀 명령:
`python -m unittest test_yolo_gpu_backends test_yolo_inference test_local_yolo_inference test_inference_contract test_model_sidecar_config -v`

기존 실패는 test_cpu_transition_is_rejected_even_if_output_returns_to_gpu이다.
GPU→CPU 전환은 거절되지만 기존 Step 복구 동작이 오류를 처리하므로
테스트의 예외 전파 기대와 일치하지 않는다. 별도 프로세스에서 HEAD의
yolo_backend.py를 메모리로 로드한 뒤 같은 테스트를 실행해 동일 실패를 재현했다.
이번 변경 범위의 실행 복구 동작은 수정하지 않았다.
