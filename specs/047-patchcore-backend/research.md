# 연구 결과

## 결정과 근거
학습 프로젝트는 자체 구현으로 patchcore-v1을 직접 지원한다.
ResNet18 layer2·layer3의 384차원 특징과 메모리 뱅크를 동일하게 복원한다.
weights=None 생성 후 엄격한 state_dict 로딩으로 다운로드를 방지한다.
내부 resize·정규화·청크 검색을 유지해 원시 점수와 임계값 의미를 보존한다.
출력은 pred_score [B], anomaly_map [B,H,W]이며 임계값·메타데이터는 속성으로 보존한다.
값 범위 검사는 CPU 동기화가 생겨 호출자 계약으로 둔다.

## 검토한 대안
TorchScript는 현재 result.pt 형식과 다르다. anomalib은 필요 없으며 의존성이 늘어난다.
별도 Step은 기존 범용 텐서 계약으로 충분하므로 추가하지 않는다.

## 독립 연구
계획 단계 연구 에이전트가 학습 구현과 GPU 감시·배치 분리 호환성을 확인했다.
