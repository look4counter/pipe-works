# 기능 명세: PatchCore 실행부

작성일: 2026-10-22 · 상태: 명확화 완료
입력: yolo-trainer의 ResNet18 기반 patchcore-v1 결과를 src에서 실행한다.

## 사용자 시나리오 및 검증

### 사용자 이야기 1 — 학습 결과 실행 (우선순위: P1)
사용자는 result.pt와 준비한 GPU 이미지를 전달해 이상 점수와 맵을 받는다.
가치: 재학습 없이 기존 학습 결과를 사용한다.
독립 검증 및 수용 조건: 동일 가중치·입력으로 학습 프로젝트 기준 결과와 비교한다.
단일 및 여러 이미지의 점수와 맵이 허용 오차 내 일치해야 한다.

### 사용자 이야기 2 — 기존 실행 경로 사용 (우선순위: P2)
사용자는 기존 Step에서 patchcore를 선택하고 공유 배치를 사용한다.
가치: 기존 파이프라인 계약을 유지한다.
독립 검증 및 수용 조건: 단독 결과와 공유 배치 결과가 일치하고 요청별로 분리된다.

### 경계 조건
지원하지 않는 형식·backbone, 빈/잘못된 메모리 뱅크, 손상 가중치,
잘못된 입력 형태·자료형·장치는 명확한 오류로 거절한다.

## 요구사항

### 기능 요구사항
- FR-001: patchcore-v1의 ResNet18 가중치와 정상 메모리 뱅크를 함께 복원한다.
- FR-002: RGB BCHW float32 0~1 입력에 학습과 동일한 resize·정규화를 적용한다.
- FR-003: 원시 점수 [B]와 입력 해상도 맵 [B,H,W]를 GPU 텐서로 제공한다.
- FR-004: 기존 backend 선택 및 단일·공유 배치와 GPU 전용 제약을 유지한다.
- FR-005: 잘못된 모델·입력을 거절하고 가중치를 다운로드하지 않는다.
- FR-006: 임계값·메타데이터를 보존하되 자동 판정이나 사용자 후처리를 추가하지 않는다.

### 주요 개체
모델: 형식, backbone, 입력 크기, 가중치, 메모리 뱅크, 임계값, 메타데이터.
결과: 이미지별 원시 점수와 이상 맵.

## 성공 기준
- SC-001: 기준 점수·맵과 rtol=1e-4, atol=1e-5 이내 일치한다.
- SC-002: 두 공유 배치 요청의 결과가 각각 단독 결과와 허용 오차 내 일치한다.
- SC-003: 모델·입력 오류가 정상 결과로 오인되지 않고 전달된다.

## 가정
학습, 영상 전처리·후처리, 예제는 사용자가 작성한다. 제품 구현은 src에 한정한다.
anomalib과 학습 프로젝트를 의존성으로 추가하지 않는다.
입력 값 범위는 호출자 계약이며 매 추론마다 CPU 동기화로 검사하지 않는다.

## 명확화 검토
대화와 학습 코드로 형식·입출력·범위가 확정됐다. 질문 0개.
기능·데이터·오류·통합·품질·범위 범주의 중대한 모호성 없음.
