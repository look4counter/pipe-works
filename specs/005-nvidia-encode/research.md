# 설계 검토: NVIDIA 비디오 인코딩

- **결정**: 인코딩 단계에서 압축 결과를 PyAV 패킷으로 변환한다. 송출 단계는 이미 패킷 입력 계약을 사용한다.
- **반환 구조**: 실제 실행 오류에서 `bytes()`가 사전을 포함한 결과에 적용된 것이 드러났다. 제공된 동작 코드와 같이 반환값을 결과 항목별로 순회하고 각 항목에서 압축 바이트를 추출한다.
- **시간 정보**: B 프레임을 사용하지 않는 설정에서 출력 패킷에 순차 PTS·DTS를 주고 FPS의 역수를 시간 기준으로 쓴다.
- **종료 처리**: 정상 종료 시 `EndEncode()`의 잔여 결과를 같은 변환 경로에 넣는다.
- **범위 제한**: 현재 구현은 입력 도중 스트림 변경 시 인코더를 다시 만들지 않는다. 실제 GPU 동작은 모의 검증만으로 확정할 수 없다.
