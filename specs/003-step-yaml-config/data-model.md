# 자료 모델: 단계 설정과 컨텍스트

- **파이프라인 설정**: YAML의 최상위 매핑을 `SimpleNamespace`로 보관한다.
- **단계 설정**: 원래 단계 클래스명에 해당하는 매핑을 `SimpleNamespace`로 변환해 `configure()`에 전달한다. 없는 섹션은 빈 객체다.
- **핫스왑 설정**: 사용자 정의 단계의 래퍼가 설정 객체를 보관하고 새 단계 인스턴스에 다시 전달한다.
- **파이프라인 컨텍스트**: 필드 없는 동적 객체다. RTSP 소스는 `packet`과 `video_stream`을, 디코더는 `frame` 등을, 인코더는 새 `packet` 등을 출력 객체에 채운다.
