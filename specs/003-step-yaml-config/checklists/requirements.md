- [x] 사용자 정의 Step의 선택적 적용과 내부 Step 설정 전달을 구분했다.

- [x] 전체 YAML과 단계 섹션의 구조 검증 시점을 명시했다.
- [x] 클래스명에 따른 등록 시 설정 전달과 누락 섹션의 동작을 명시했다.
- [x] 필수 `Step.configure()`와 핫스왑 래퍼의 설정 보관 책임을 구분했다.
- [x] 동적 컨텍스트의 동일 객체 전달과 새 출력 객체 경계를 명시했다.
