# GPU 박스 그리기 명세

- FR-001: BoxOverlay는 detections.boxes.xyxy의 GPU 텐서를 직접 사용하고 CPU 복사·Python 박스별 반복·좌표 스칼라 추출을 하지 않는다. detections 객체와 원본 프레임 식별은 보존한다.
- FR-002: NV12 테두리 색·두께·좌표 반올림·경계 자르기·중첩 박스와 keep_previous를 유지한다. 빈 결과는 이전 박스를 지우며 크기·장치 변경에서도 이전 박스를 초기화한다.
- SC-001: CUDA 픽셀·보관·빈 결과·경계·CPU 접근 금지 검증이 통과한다.

명확화: GPU 텐서 입력만 허용하고 CPU 좌표는 거부한다. 비유한 좌표와 역전 박스는 그리지 않는다. 최신 요청으로 기존 CPU 목록 보관을 대체한다. 추가 질문은 필요하지 않다.
