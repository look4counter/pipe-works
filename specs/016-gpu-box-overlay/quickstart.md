# GPU 처리 검증

BoxOverlay는 detections.boxes.xyxy를 GPU 텐서로 직접 읽으며 detections 객체는 유지한다. GPU 차분 배열과 누적합으로 테두리를 계산하고 NV12 휘도·색차에 적용한다. CPU 좌표 복사·스칼라 추출과 Python 박스별 반복은 제거했다. keep_previous는 GPU 복제 텐서를 보관한다. 임시 마스크 크기는 박스 수와 무관하고 영상 해상도에 비례한다.

명세·명확화·계획·작업의 일관성을 확인했다. 기존 CUDA 픽셀·자르기·이전 박스·빈 결과 검증과 CPU 접근 금지 검증을 수행했다. GPU 메모리와 연산은 필요하므로 성능 개선 폭은 실제 영상에서 비교해야 한다. 최종 수렴 점검에서 추가 구현 차이는 없다.
