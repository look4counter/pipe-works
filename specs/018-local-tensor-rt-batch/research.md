# 모델 경로 초기화 시 검증 조사

결정: 기존 정규 경로 작업자 레지스트리에 입력 경로별 별칭 캐시를 추가한다. 상대경로는 CWD를 포함해 다른 작업 디렉터리의 모델과 혼동하지 않는다. 생성 성공 이후에만 저장하며 정규 작업자 캐시가 비워지면 다시 검사한다.

근거: 매 추론 resolve/is_file은 이미 메모리에 로드된 모델 사용에 필요하지 않다. TensorRT 세션의 read_bytes와 YOLO 최초 로더는 계속 파일을 사용하므로 최초 준비와 실패 후 재시도의 오류 전달은 유지된다. 상대경로를 문자열 하나로 영구 캐시하는 대안은 작업 디렉터리 변경 시 잘못된 모델을 사용하므로 제외한다. 전체 파일 감시와 자동 재로드는 요청 범위 밖이다. 캐시된 심볼릭 링크 별칭의 대상 고정은 초기화 기준 계약으로 명시한다.
