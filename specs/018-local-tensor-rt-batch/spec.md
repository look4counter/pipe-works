# TensorRT 공유 배치 모듈

- FR-001: local_tensor_rt.infer는 GPU 텐서 또는 이름별 GPU 텐서 사전을 받아 엔진·GPU·이름·자료형·비배치 형상이 같은 요청을 공통 수집기로 묶는다. 개별 요청은 배치 축 0의 크기 1이며 출력도 배치 축 0으로 분리 가능해야 한다.
- FR-002: 모델 동명 YAML의 max_batch_size·밀리초 timeout으로 수집하고 plugins로 엔진을 로드한다. 설정 파일이 없으면 배치 1·수집 0으로 처리한다. timeout은 추론 제한 시간이 아니다.
- FR-003: 준비 이벤트를 기다려 입력을 배치 GPU 텐서로 구성하고 전용 작업자로 동기 추론한다. 결과는 GPU의 배치 1 텐서 사전으로 각 요청에 전달한다. 오류는 모든 배치 요청에 전달하며 다음 요청에서 재시도한다. 입력 수명과 완료를 보장한다.
- FR-004: 이번 작업은 모듈 추가이며 TensorRTInference의 batch 옵션 연결은 제외한다.
- SC-001: 실제 GPU에서 호환·비호환 요청·결과 분리·오류 복구·설정 검증이 통과한다.

명확화: 일반 TensorRT의 임의 출력 의미는 추론할 수 없으므로 배치 축 0 계약을 명시적으로 제한한다. 고정 배치 1 엔진은 max_batch_size=1로 사용해야 한다. 추가 질문은 필요하지 않다.
