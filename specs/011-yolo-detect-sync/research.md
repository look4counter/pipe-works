# 동기 GPU 감지 설계 조사

- 결정: 기존 GPU 변환·패딩·예측기와 원본 좌표 복원을 유지한다.
- 근거: 기본 Ultralytics 예측기의 NumPy 변환을 우회해 영상·감지 텐서의 CPU 복사를 막아야 한다.
- 대안: CPU 경로나 공유 배치 추론은 이번 단일 감지 계약과 다르다.
- 결정: 입력 준비 이벤트를 기다리는 별도 CUDA 추론 스트림에서 동기 실행하고 원본을 작업 완료까지 보관한다. Python 작업자와 GPU 스트림 분리는 서로 다른 개념이다.
- 근거: 별도 스레드와 입력 복제 없이도 입력 순서와 표면 수명을 보장한다.
- 결정: 모델 동명 YAML을 읽지 않고 예외를 전파한다.
- 근거: 지연·오류 통과 정책은 공통 Async가 선택적으로 적용한다.
- 결정: TensorRT의 슬롯 관리 메서드를 해당 작업자로 옮긴다.
- 근거: 제거할 YOLO 작업자를 상속한 기존 의존성을 끊고 TensorRT의 동작은 유지한다.
