# 비동기 GPU 단일 감지 검증 안내

CUDA 사용 가능한 PyTorch, Ultralytics 및 예제 `.pt`·`.engine` 모델이 필요하다.

모델이 `models/model.pt`이면 `models/model.yml`에 `timeout: 5`를 설정한다. 단위는 밀리초다. 파일·항목 부재도 5ms이며 실제 모델 초기화 검증에는 임시 동명 YAML에 충분한 제한 시간을 설정한다.

저장소 루트에서 `.venv/Scripts/python.exe -m unittest discover -s tests -p test_yolo_detect.py`를 실행한다. CPU 복사 호출 차단, 모델 재사용, 간격, 오류 복구, 원본 좌표 및 실제 모델의 CUDA 결과를 확인한다.

이벤트로 초기화나 추론을 정지하는 검증에서는 제한 시간 이후 첫 프레임과 후속 프레임이 결과 없이 전달되어야 한다. 입력 종료·반복자 닫기와 같은 단계 재실행에서도 정지한 추론을 기다리거나 작업자를 늘리지 않아야 한다. 늦은 완료가 이미 전달된 컨텍스트를 수정하지 않는지도 확인한다.

공유 변환 회귀는 `test_local_yolo.py` 및 `test_yolo_detect_batch.py`를 같은 방식으로 실행한다. 결과 계약은 [감지 계약](contracts/detection.md)을 따른다.

## 2026-10-08 GPU 전환 시 실행 결과

- 단일 단계: 12개 중 11개 통과, 실제 `.engine` 검증 1개 건너뜀.
- 배치 단계: 16개 모두 통과.
- 공유 GPU 경로: 6개 중 5개 통과, 실제 모델 복합 검증에서 `.engine` 파일 부재로 1개 건너뜀. 해당 검증의 `.pt` 경로는 실행되었다.
- 실제 `.pt`는 입력·결과의 `.cpu()`와 `.numpy()` 호출을 차단한 상태에서 추론에 성공했고 결과 영상·박스가 CUDA에 남았다.
- `.engine` 모델 파일 및 ONNX·TensorRT 관련 패키지가 없어 엔진 생성과 실제 엔진 검증은 완료하지 못했다. 엔진 파일을 준비한 환경에서 실행하면 조건부 검증이 수행된다.
- 변경 파일의 공백 오류 검사는 통과했다.

## 2026-10-08 비동기 전환 시 실행 결과

- 단일 단계: 14개 중 13개 통과, 실제 `.engine` 모델 부재로 1개 건너뜀.
- 배치 단계: 16개 모두 통과.
- 공유 GPU 경로: 6개 중 5개 통과, `.engine` 모델 부재로 1개 건너뜀.
- 제한 시간 파일·단위·기본값·0·잘못된 값, 초기화 지연, 추론 지연·실패, 사용 중 건너뜀, 늦은 결과 폐기, 종료·재실행 자원 상한, 별도 CUDA 스트림과 요청 실행별 통계를 확인했다.
- 실제 `.pt` 모델도 비동기 작업자에서 CPU 복사 차단 상태로 GPU 결과를 반환했다. 실제 엔진 검증은 파일과 관련 패키지를 준비한 환경에서 필요하다.
- 수렴 보완 후 단일 단계 검증을 다시 실행하여 13개 통과·1개 건너뜀을 확인했다. 추론 실패도 시간 통계에 포함하며 모델 로드 실패는 포함하지 않는다.
