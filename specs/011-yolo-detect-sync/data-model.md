# 비동기 감지 데이터 모델

- 입력: 기존 `PipelineContext`의 GPU uint8 NV12 영상, CUDA 스트림, 너비·높이. 너비와 높이는 양의 짝수이며 입력 장치는 설정 GPU와 일치해야 한다.
- 추론 입력: GPU RGB float 텐서, 크기 `(1, 3, 640, 640)`, 값 범위 0~1.
- 결과: 기존 `PipelineContext.detections`에 Ultralytics 결과를 연결한다. `orig_img`는 원본 크기의 GPU RGB HWC 텐서이며 박스 데이터는 원본 좌표의 GPU 텐서다.
- 요청: GPU NV12 복제, 원본 프레임 소유자·DLPack 텐서, 준비 이벤트, 제출 시각, 옵션 사본, 실행 문맥, 완료 이벤트, 폐기 표시와 결과.
- 작업자: 단계 인스턴스별 데몬 스레드 1개, 요청 슬롯 1개, 사용 여부·종료 신호, GPU 스트림과 모델. GPU 변경 시 모델과 스트림을 다시 구성한다.
- 상태: 입력 → 선택 또는 건너뜀 → 슬롯 확보 → GPU 복제·제출 → 제한 시간 안 완료 또는 시간 초과. 완료 결과만 원래 프레임에 연결한다. 시간 초과 요청은 실제 종료까지 슬롯을 유지하며 이후 프레임은 결과 없이 전달한다.
- 종료: 신규 제출을 막고 현재 추론이 돌아오면 자원을 해제한다. 종료 호출 자체는 추론을 기다리지 않는다.
