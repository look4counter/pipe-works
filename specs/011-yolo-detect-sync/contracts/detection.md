# 비동기 단일 감지 단계 계약

생성자와 `configure` 설정은 기존과 같다. `process`는 입력 객체와 순서를 유지하는 반복자이며 추론은 별도 작업자에서 실행한다. 첫 프레임부터 지정 간격으로 추론 대상을 선택한다. 작업자 사용 중에는 추론을 건너뛴다.

입력 영상과 감지 텐서의 CPU 복사는 금지한다. 성공 결과는 원본 해상도와 CUDA 장치를 유지한다. 영상은 RGB float HWC이며 NumPy 배열이 아니다. 표시·저장 기능은 사용하지 않는다.

잘못된 입력, 장치 불일치, 모델 또는 추론 오류는 로그를 남기고 해당 프레임을 감지 결과 없이 전달한다. 빈 박스 결과는 정상이다. 다음 프레임을 계속 처리한다.

`models/model.pt`와 `models/model.engine`는 `models/model.yml`의 `timeout`을 읽는다. 단위는 밀리초이며 유한한 0 이상 숫자만 허용한다. 파일·항목이 없으면 5ms다. 배치용 `max_batch_size`와 함께 적어도 된다. 단일 단계에서는 제출부터 결과 완료까지 기다리는 최대 시간을 뜻하며, 배치에서는 요청을 모으는 시간이다.

시간 초과·실패·사용 중인 작업자로 건너뛴 프레임은 `detections=None`이다. 늦은 결과를 다른 프레임에 적용하거나 이미 전달한 컨텍스트를 수정하지 않는다. 입력 종료와 반복자 닫기는 작업자 완료를 기다리지 않는다.
