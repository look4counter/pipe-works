# 요구사항 점검

## 좌표 복원 분리 품질 점검

- [x] 후처리 독립성과 세 변환의 수용 시나리오를 정의했다.
- [x] 좌표 형식·빈 결과·경계·추가 열·크롭 한계를 명확히 했다.
- [x] GPU 처리·수명 계약·검증 가능한 성공 기준을 정의했다.
- [x] 미확정 사항이나 추가 질문이 없다.


- [x] 실제 엔진 형식과 처리 범위가 명확하다.
- [x] 원본 보존·GPU 처리·누락 결과와 설정 오류가 정의되었다.
- [x] 성공 기준과 작업이 요구사항에 대응한다.

## 범용 전처리 후속 품질 점검

- [x] 모델별 전처리와 기존 파이프라인 호환 시나리오를 정의했다.
- [x] 세 가지 변환·출력 형식·정규화·설정 우선순위의 수용 조건을 정의했다.
- [x] 최소 패딩·중앙 자르기·비균일 배율·잘못된 값의 경계를 명확히 했다.
- [x] 모델 공급자 의존성 없이 동작하고 GPU에서 원본을 보존하는 범위를 정했다.
- [x] 성공 기준은 구성 및 수치 검증으로 확인 가능하고 미확정 사항이 없다.
