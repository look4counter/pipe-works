# 이미지 좌표 복원 계약

전처리는 context.tensor_rt_transform으로 변환 객체를 전달한다. 후처리는 구체 클래스나 변환 방식을 해석하지 않는다.

- shape: 원본 (높이, 너비).
- restore_boxes_(boxes): 모델 입력 픽셀 기준 xyxy의 N×4 이상 실수 텐서를 원본 좌표로 제자리 복원하고 같은 텐서를 반환한다. 추가 열과 빈 결과를 보존한다.
- 각 축은 (좌표 − 이동량) / 축별 배율로 계산하고 원본 경계로 제한한다. 크롭 이동량은 음수이며 잘린 영상은 재생성하지 않는다.
- CPU 복사·CUDA 동기화를 추가하지 않고 후처리 모델 스트림에서 호출한다.
- 기존 정보 속성은 호환을 위해 제공하지만 후처리 계약에는 포함하지 않는다.
