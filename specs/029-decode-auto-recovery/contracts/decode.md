# 디코더 복구 계약

NvidiaDecode의 생성자와 설정은 변경하지 않는다. 복구 가능한 네이티브 예외에 자동 복구를 기본 적용한다. 입력 패킷의 is_keyframe 및 video_stream 객체 교체를 사용한다.

복구 중 출력 프레임이 잠시 없을 수 있다. 정상 키프레임과 헤더가 들어오면 새 디코더로 출력한다. 오류 원인 경고와 실제 프레임 출력 재개 정보를 기록한다. 지원하지 않는 코덱과 네이티브 지원 불가 예외, 소스 및 후속 처리 오류는 기존처럼 전파한다. 네이티브 프로세스 충돌은 Python 예외 복구로 처리하지 못한다.
