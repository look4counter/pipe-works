# 자료 모델: Step 핫스왑

## 등록 단계

- **원래 Step**: 사용자가 `.step(...)`에 전달한 인스턴스. YAML 섹션 이름과 `configure()` 호출의 기준이다.
- **교체 래퍼**: 원래 Step을 실행 중 보관한다. 첫 등록 단계만 입력을 소비하지 않는 소스 구간으로 취급한다.
- **소스 파일**: 원래 Step 클래스가 정의된 파일. 내용 해시가 변경되면 새 구현 후보를 준비한다.

## 실행 구간

- **공유 입력 커서**: 상류 반복자와 경계에서 잠시 보관한 항목 하나를 유지한다.
- **구간 반복자**: 현재 Step에 전달하는 입력. 파일 변경이나 상류 세대 변경 때 다음 입력 요청에 종료를 알린다.
- **구현 후보**: 격리된 모듈에서 불러온 새 Step 클래스. 준비 실패 시 현재 구현을 유지한다.
- **세대 식별자**: 출력 컨텍스트에 붙는 내부 속성 `_pipeworks_hotswap_epoch`. 하류 단계가 상류 교체 경계를 감지하는 데 사용한다.

사용자 Step의 공개 처리 계약은 계속 `process(inputs) -> Iterator[PipelineContext]`다. 세대 식별자는 실행기가 관리하며 Step 작성자가 직접 생성할 필요가 없다.
