# 공개 계약

`from pipeworks.embedded import YoloDetectReport, TensorRTReport`로 가져온다. 생성자는 인수가 없고 1초마다 출력한다. Report는 해당 감지 단계 뒤, CudaAsync 바깥에 둔다. 입력과 순서를 보존한다.

단계별 CPU/GPU 시간을 ms로 표시한다. 직전 1초와 최근 10초 평균 및 표본 수를 제공한다. 미완료 GPU 표본은 GPU 평균에서 제외한다. 기록이 없는 구간은 없음이다. 공유 배치의 시간은 요청별 배치 지연이며 총 GPU 비용이 아니다.

완료는 감지 작업 완료, 타임아웃은 호출자의 결과 대기 만료다. 같은 요청에 두 상태가 존재할 수 있다. 만료로 후속 단계가 실행되지 않으면 부분 종료로 표시하고 완료에 포함하지 않는다. StreamReport의 추론 통계 의미는 유지한다.
