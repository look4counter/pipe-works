# 설계 검토: RTSP 패킷 송출

- **입력 계약**: 원본 수신과 인코딩 단계가 같은 `packet`, `video_stream` 필드를 사용하도록 송출 입력을 단일화한다.
- **이유**: 송출 단계가 인코딩 바이트를 새 패킷으로 만드는 분기는 중복이다. 인코더가 송출 가능한 객체를 제공할 책임이 있다.
- **시간 정보**: 입력 패킷의 PTS, DTS, 지속 시간과 시간 기준으로 시간 순서를 보정한다.
- **실패 복구**: 출력 실패 후 입력 흐름을 멈추지 않고 단조 시계로 재시도 시점을 판단한다.
- **출력 옵션**: PyAV 옵션 값은 문자열로 전달한다. 제한 시간 설정은 초이며 출력 옵션에는 마이크로초로 변환한다.
- **단계 경계**: 송출 단계는 패킷을 소비한다. 압축 바이트를 패킷으로 만드는 방법은 [NVIDIA 인코딩 설계 검토](../005-nvidia-encode/research.md)에 둔다.
