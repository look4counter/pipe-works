# 검증 안내: RTSP 패킷 송출

1. `python -m unittest discover -s tests -p test_rtsp_publish.py`로 송출 계약을 검증한다.
2. 패킷과 비디오 스트림이 있는 입력은 송출되고, 누락된 입력과 인코딩 바이트 전용 입력은 거부되는지 확인한다.
3. 누락·역행 DTS 보정과 입력 스트림 변경 시 출력 재연결을 확인한다.
4. 출력 실패 뒤 재시도와 입력 종료 또는 예외 시 자원 정리를 확인한다.
5. 패킷 크기 1200과 제한 시간 10초가 문자열 `1200`, `10000000`으로 출력 옵션에 전달되는지 확인한다.
6. 인코딩 단계의 출력 검증은 [NVIDIA 인코딩 검증 안내](../005-nvidia-encode/quickstart.md)를 따른다.
