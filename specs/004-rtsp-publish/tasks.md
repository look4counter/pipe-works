# 작업 목록: RTSP 패킷 송출

**명세**: [기능 명세](spec.md)  
**계획**: [구현 계획](plan.md)

## 단계 1: 입력 계약

- [x] T001 `PipelineContext`의 패킷·스트림 속성과 송출 단계의 입력 계약을 확인한다. (FR-001, FR-002)
- [x] T002 두 속성이 없는 입력과 인코딩 바이트 전용 입력의 오류 동작을 검증한다. (FR-002, FR-004, SC-002)

## 단계 2: 패킷 송출

- [x] T003 `RTSPPublish.process`에서 입력 스트림을 템플릿으로 출력 스트림을 만들고 패킷을 송출한다. (FR-003, SC-001)
- [x] T004 인코딩 바이트 전용 분기와 FPS 기반 타임스탬프 생성을 제거한다. (FR-004)
- [x] T005 누락되거나 역행하는 DTS를 패킷 시간 정보로 보정한다. (FR-005, SC-003)
- [x] T006 입력 스트림 설정이 바뀌면 출력을 다시 열고 시간 상태를 초기화한다. (FR-006, SC-003)

## 단계 3: 출력 관리

- [x] T007 출력 열기·송출 실패 후 재시도와 재연결 비활성 오류 전달을 구현한다. (FR-007, SC-004)
- [x] T008 입력 종료나 처리 중 예외 발생 시 출력 연결을 닫는다. (FR-008, SC-004)
- [x] T009 통계 없이 입력을 소비하고 다음 단계로 패킷을 전달하지 않는다. (FR-009)
- [x] T010 재연결 여부·간격, 전송 방식, 제한 시간, 패킷 크기 설정을 적용한다. (FR-010)
- [x] T011 출력 옵션을 문자열로 전달하고 제한 시간을 밀리초에서 마이크로초로 변환한다. (FR-011, SC-005; 변경 명세는 003의 FR-013·014)

## 단계 4: 검증과 수렴

- [x] T012 단일 패킷 경로, 입력 오류, DTS 보정, 스트림 변경, 실패 복구, 출력 옵션을 모의 출력으로 검증한다. (SC-001~SC-005)
- [x] T013 송출 테스트와 전체 테스트를 실행하고 결과를 확인한다. (SC-001~SC-005)
- [x] T014 명세·계획·작업 목록과 코드의 차이를 점검한다. (FR-001~FR-011)
