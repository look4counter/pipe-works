# 기능 명세: 모델 동명 설정 복원

작성일: 2026-10-17
상태: 검증 완료

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 모델별 단일 설정 (우선순위: P1)
개발자는 models/model.plan에 대해 models/model.yml 하나로 배치 설정을 관리한다.
인수 조건: 설정 경로를 인자로 받지 않으며 모든 공유 요청이 동일 모델의 동명 파일을 사용한다.

## 요구사항

- FR-001: YoloInference, 공유 infer 및 TensorRTBackend의 config_path 인자를 제거한다.
- FR-002: 모델 경로의 확장자를 .yml로 바꿔 자동 로드한다. 파일이 없으면 배치 크기 1·대기 0을 사용한다. .yaml 및 다른 이름은 탐색하지 않는다.
- FR-003: 공유 작업자는 백엔드와 정규 모델 경로로 구분한다. 설정 경로로 분리하지 않으며 기존 경로 별칭 캐시를 유지한다.
- FR-004: max_batch_wait_ms 명칭·단위·값 검증, 이전 키 오류, 외부 plugins 미지원, batch_process별 프로세스 분리를 유지한다.
- FR-005: 예제·문서·테스트를 복원 계약에 맞게 갱신한다.

## 성공 기준

- SC-001: 동명 파일 로딩·미존재 기본값·잘못된 YAML 오류·생성자 인자 제거 검사가 통과한다.
- SC-002: 동일 모델 경로 별칭은 작업자를 재사용하고 다른 모델과 백엔드는 분리한다.
- SC-003: 실제 GPU·TensorRT·중앙 프로세스의 배치 회귀 검사가 통과한다.

## 경계 조건과 가정

공유 작업자는 최초 생성 시 설정을 읽고 자동 재로딩하지 않는다. 같은 내용의 다른 파일 경로는 다른 모델로 취급한다. 상대 모델 경로의 기준과 로컬·중앙 라우팅은 변경하지 않는다.

## 명확화 검토

사용자가 동명 .yml 자동 탐색을 명시적으로 선택했다. 기능·오류·의존성·완료 조건에 중대한 불명확성이 없으며 질문은 0건이다. 헌법은 미작성 템플릿이다.
