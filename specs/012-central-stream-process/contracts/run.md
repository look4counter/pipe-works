# 실행 계약

- `Pipeline.run()`은 해당 스트림이 끝날 때까지 대기한다.
- 정상 완료는 반환하고 실패는 예외를 발생시킨다.
- `KeyboardInterrupt` 또는 호출자 종료는 해당 실행의 취소를 요청한다.
- 두 호출자가 실행한 스트림은 하나의 중앙 프로세스에 존재한다.
- 중앙 프로세스에는 영상 프레임 또는 GPU 텐서를 담은 요청·응답이 없다.
# 표준 출력 전달

`Pipeline.run()`을 호출하는 동안 해당 파이프라인 실행 스레드의 표준 출력은 호출자의 표준 출력으로 전달된다. 출력은 실행 중 도착 순서대로 표시되며 기존 완료 또는 오류 결과는 그대로 유지된다.
