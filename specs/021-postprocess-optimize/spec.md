# 기능 명세: TensorRT 후처리 최적화

작성일: 2026-10-10. 상태: 명확화 완료.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 동일한 감지를 더 적은 비용으로 처리 (우선순위 P1)

기존 YOLO11 후처리 사용자는 설정 변경 없이 동일한 박스·점수·클래스를 받는다.
독립 검증: 기존 후처리와 같은 예측 텐서의 결과 및 처리 시간을 비교한다.

1. 클래스 목록·신뢰도·IoU·최대 감지 수를 바꾸어도 기존 선택 기준을 유지한다.
2. 빈 결과와 실패에서도 기존 출력 형식·버퍼 정리·완료 대기를 유지한다.

### 경계 조건

빈 후보, 빈 클래스 목록, 최대 클래스가 선택 목록 밖인 후보, 중복 클래스, 동점 점수, 임계값 경계, 최대 후보 제한, 출력 개수 6의 기존 라이브러리 특례를 비교한다.

## 요구사항

- FR-001: 기존 FP32 (1,84,N) 입력과 모든 후처리 설정을 유지한다.
- FR-002: 전체 클래스 중 최고 점수를 먼저 선택하고 클래스 필터를 적용한다. 선택 클래스만으로 최고 점수를 계산하지 않는다.
- FR-003: 클래스별 NMS와 최대 30000 후보 제한, max_det 및 입력 좌표 변환 동작을 유지한다.
- FR-004: 좌표 복원 결과·입력 GPU·완료 대기·오류 시 정리 계약을 유지한다.
- FR-005: 독립 참조 비교 테스트와 준비 실행 이후 비교 측정 도구를 제공한다.

## 성공 기준

- SC-001: 유한 예측의 결과는 기존 구현 대비 rtol=1e-5, atol=1e-5로 일치한다. NMS 동점은 같은 커널을 사용한다.
- SC-002: 후보의 반복 동적 필터링과 좌표 복원의 고급 인덱싱을 줄인다.
- SC-003: 동일 합성 입력에서 기존식과 변경식의 후처리 경과 시간을 기록한다. 전체 영상 파이프라인 성능으로 확대 해석하지 않는다.

## 가정과 명확화

범위는 기존 YOLO11 예제 후처리이며 모델·정밀도·감지 임계값을 변경하지 않는다. 핵심 모호성은 없고 질문은 필요하지 않다.
