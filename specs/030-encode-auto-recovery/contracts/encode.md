# 인코더 복구 계약

공개 생성자 NvidiaEncode(*, gpu_id=0, fps=30)와 YAML 키는 유지한다. 복구 가능한 네이티브 생성·프레임 처리 오류에 기본 자동 복구를 적용한다. 실패 프레임과 재시도 대기 중 입력은 버리고 실패 후 최소 1초 간격으로 최신 입력에서 재시도한다.

새 인코더는 재생 가능한 시작 프레임과 필요한 헤더를 출력하며 PTS/DTS와 시간 기준은 세대 간 유지된다. 정상 입력 종료의 잔여 출력은 기존 패킷 계약을 따르며 복구 가능한 종료 오류는 경고 후 버린다. 복구 원인과 실제 출력 재개를 기록한다.

입력 스트림 객체 또는 코덱·해상도·픽셀 형식·CUDA 처리 스트림 변경을 감지한다. 소스·설정·지원 불가·후속 처리 및 복구 불가능한 GPU 오류는 전파한다. 네이티브 프로세스 충돌 복구는 포함하지 않는다.

# 수명 보장 보완 계약

복구·입력 변경·종료 시 기존 작업이 완료되기 전에 자원을 해제하지 않는다. 마지막 제출 입력을 정리까지 유지하며 복구 예외가 이전 세대를 보유하지 않는다. 연계 디코더는 출력 풀 생성 전 오류도 동기화하고 외부 프레임 소유권을 유지한다. 동기화 실패는 전파한다. 정상 프레임별 CPU 동기화는 추가하지 않는다.
