# 데이터 모델

## 복구 세대의 소유권

인코더의 마지막 입력은 정리 경계까지 유지한다. 복구 오류는 문자열만 가진 일시 객체이며 이전 코덱의 bound method를 소유하지 않는다. 디코더 풀은 닫힌 후에도 외부 Tensor 소유자가 있는 동안 디코더와 디코딩 스트림을 함께 유지한다. 세대 정리는 작업 완료 대기 → 코덱 해제 → 실행 스트림 해제 순서다.

## 인코딩 세대

입력 스트림 객체, 코덱·크기·픽셀 형식·CUDA 핸들 식별값, 인코더 및 CUDA 스트림 참조를 유지한다. 객체 또는 식별값 변경 시 기존 정상 세대를 종료하고 최신 입력으로 교체한다.

## 복구 상태

정상 → 오류 프레임 폐기·인코더 해제 → 단조 시계 기준 1초 대기 → 최신 프레임으로 재생성 → 실제 압축 패킷 출력 후 복구 완료. 재실패 시 대기로 돌아간다. 대기 큐는 만들지 않는다.

## 시간 정보

process 시작의 정수 FPS와 time_base는 실행 동안 고정한다. next_pts는 게시한 패킷 수만큼 증가하며 인코더 재생성에도 초기화하지 않는다.
