- 최신 프레임 전용 테스트 13개 통과. 실제 CUDA 텐서의 원본 버퍼 재사용 검증을 포함한다.

- 실제 NVDEC/NVENC 실행은 로컬 PyNvVideoCodec DLL 누락으로 검증할 수 없다.

## 무복사 검증 결과

- 디코더 전용 19개 검증 통과. 실제 NVDEC 후속 디코딩 중 첫 잠금 버퍼의 내용과 포인터가 유지되고 NVENC가 공유 텐서를 소비한다.
- 영상 clone과 CPU Stream.synchronize를 금지한 실제 디코더 테스트 통과. 이벤트 동기화는 종료 정리에서 허용한다.
- 공유 텐서와 DLPack 별칭의 마지막 참조가 끝날 때까지 버퍼가 잠기며, 조기 종료 후 외부 참조도 보호됨을 확인했다.
- 관련 회귀 검증 총 182개 실행: 181개 통과, 기존 GPU 장치 조건 1개 건너뜀. 보고서·RTSP·핫스왑·CudaAsync·YOLO·TensorRT를 포함한다.
- 입력 카메라의 장시간 FPS 회복은 운영 스트림에서 별도로 확인한다.
