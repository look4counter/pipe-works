# 자료 모델: NVIDIA 비디오 디코딩

## 입력 패킷 컨텍스트

- `packet`: 압축 영상 패킷. 바이트열로 변환 가능하며 선택적으로 PTS가 있다.
- `video_stream`: 코덱 이름을 가진 입력 비디오 스트림.

## 디코더 상태

- 첫 패킷에서 생성한 NVIDIA 디코더.
- GPU 번호에 해당하는 CUDA 스트림.
- 디코더가 보고한 출력 픽셀 형식.

## 출력 프레임 컨텍스트

- `frame`: 디코더가 반환한 프레임 한 개.
- `video_stream`: 입력에서 받은 비디오 스트림.
- `cuda_stream`: 디코딩에 사용한 CUDA 스트림.
- `pixel_format`: 디코더의 출력 픽셀 형식.

입력 패킷 한 개에서 출력 프레임이 0개 이상 나올 수 있으므로 패킷별 컨텍스트와 프레임별 컨텍스트의 객체 동일성을 요구하지 않는다. 후속 단계의 입력 계약은 [NVIDIA 인코딩 자료 모델](../005-nvidia-encode/data-model.md)에 있다.
