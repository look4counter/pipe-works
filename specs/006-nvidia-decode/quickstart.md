# 검증 안내: NVIDIA 비디오 디코딩

## 준비

모의 검증에는 디코더와 CUDA 스트림을 대체할 테스트 환경이 필요하다. 실제 디코딩에는 NVIDIA GPU와 PyNvVideoCodec이 필요하다.

## 확인 항목

1. 첫 패킷의 코덱에 맞는 디코더와 설정한 GPU의 CUDA 스트림이 만들어지는지 확인한다.
2. 패킷 PTS가 있을 때 디코더 입력에 전달되는지 확인한다.
3. 디코더가 프레임 0개 또는 여러 개를 반환할 때 컨텍스트 수가 일치하는지 확인한다.
4. 모든 출력 컨텍스트에 프레임, 비디오 스트림, CUDA 스트림, 픽셀 형식이 있는지 확인한다.
5. 입력 종료 시 `Flush()`의 지연 프레임이 출력되는지 확인한다.

네트워크 재연결만 발생했을 때의 디코더 재생성은 현재 구현 검증 항목이 아니다.
