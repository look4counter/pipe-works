# 최신 프레임 단계 계약

기존 `.step(NvidiaDecode())` 호출과 gpu_id 설정을 유지한다. 기본 동작은 최대 30개 FIFO 대기 큐 전달이다. 압축 패킷은 계속 순서대로 디코딩하지만 모든 디코딩 프레임이 후속 단계로 전달되지는 않는다.

대기 큐는 최대 30개이며 초과 시 가장 오래된 대기 프레임을 버린다. 처리 중 프레임은 교체 대상이 아니다. 출력 frame은 GPU DLPack 입력이며 기존 감지·인코딩이 소비할 수 있다. 추가 속성 decoded_at과 decode_dropped_frames로 대기 나이와 폐기를 확인할 수 있다.

영상 복사 없이 잠금 디코더 메모리를 공유한다. 잠금 출력 보관량은 최대 34개이며, 호출자가 출력을 계속 보관하면 버퍼 반환까지 생산이 대기할 수 있다. GPU 완료 이벤트 이전에 버퍼를 반환하지 않는다. decoded_at은 게시 시각이며 카메라 촬영 시각이나 GPU 완료 시각이 아니다.

조기 close는 생산자 취소를 요청하고 입력 읽기가 반환한 뒤 정리한다. 기존 RTSP timeout_ms가 종료 대기 상한을 결정한다. 입력이 취소·timeout을 지원하지 않고 영구 차단되면 종료도 그 입력에 의존한다.
