# 검증 안내

저장소 루트에서 .venv/Scripts/python.exe -m unittest discover -s tests -p test_central_shutdown.py 명령으로 단위·실제 중앙 프로세스 검증을 실행한다.
같은 방식으로 test_central_process.py를 실행해 정상 응답·실행 오류·그룹 분리를 확인한다.
통합 검증에는 Windows AF_PIPE와 중앙 프로세스를 시작할 수 있는 환경이 필요하다. 지연 정리를 재현하므로 12초 이상의 대기가 포함된다. 임시 디렉터리의 장벽 파일을 해제한 뒤 정리 완료와 서버 종료를 확인한다.

## 실행 결과 (2026-10-16)

- 수정 전: 새 검증 4개 중 2개 실패. 실제 중앙 프로세스가 정리 중 종료되는 문제와 감시 예외에서 중단·정리 대기를 건너뛰는 문제를 재현했다.
- 수정 후: test_central_shutdown.py 4개 통과(13.579초). 실제 별도 중앙 프로세스에서 기존 10초+1초보다 긴 12초 동안 정리를 보류해 생존을 확인했다. 같은 서버의 생존 확인과 별도 실행 응답을 받았으며 정리 장벽 해제 후 완료 표시와 정상 유휴 종료를 확인했다.
- 기존 test_central_process.py 30개 통과(38.119초). 정상·오류 응답, 운영·개발 그룹 분리, 연결 해제와 로그 중계를 포함한다.
- test_remote_logging.py 및 test_pipeline_routing.py 합계 16개 통과. 관련 검증 총 50개 통과.
- 테스트의 expected failure 예외 로그는 기존 오류 응답 검증의 의도된 출력이며 검증 실패가 아니다.
- git diff --check 통과. 이번 변경은 중앙 요청의 정리 대기만 다루며 별도 GPU 오류 복구와 병렬 송신 문제는 변경하지 않았다.
