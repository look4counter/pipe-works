# Sink 계약

`Sink(step)`는 일반 Step 하나를 감싼다. `Sink.process(inputs)`는 모든 입력 컨텍스트를 동일 객체로 한 번씩 다음 Step에 전달한다. 감싼 Step의 출력은 작업자가 소비하며 주 스트림으로 반환하지 않는다. 감싼 Step은 별도 작업자에서 지속적인 입력 반복자를 한 번 받는다. 작업자가 바쁘면 그때 들어온 입력은 후처리에서 건너뛴다. 정상적인 입력 종료 시 수락한 마지막 작업의 완료를 기다린다. 감싼 Step은 입력 컨텍스트를 읽기 전용으로 다뤄야 한다.

일반 내부 Step은 `Sink` 생성 시 `Hotswap`으로 감싼다. 명시적으로 전달된 `Hotswap`은 중복으로 감싸지 않는다. 내부 소스 파일 변경은 작업자가 다음 입력을 받을 때 감지한다.
