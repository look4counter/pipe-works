# 코덱 정리 및 송신 계약

GPU 작업 완료 확인 전에 정상 자원을 해제하지 않는다. 버퍼 반환·동기화가 실패하면 최초 오류를 전달하고 동일 자원의 정리 작업은 재시도하지 않는다. 실패한 풀을 신규 프레임에 재사용하지 않는다. 외부 영상 참조는 기존 소유자를 유지한다.
RTSPPublish는 원본 packet의 stream·PTS·DTS·시간 기준을 변경하지 않는다. 송신마다 별도 압축 패킷에 기존 보정과 재시도를 적용한다. 키프레임·손상 표시와 부가 데이터는 보존한다. discard·trusted·disposable 플래그는 공개 API로 보존할 수 없어 ValueError로 거부한다. 입력 파일 pos와 opaque는 출력에 복사하지 않는다.
프레임·GPU 버퍼 복사는 없으며 압축 패킷 데이터 복사 1회가 추가된다. 입력 패킷 자체를 사용자 코드가 동시에 수정하는 것은 지원하지 않는다.
