# 기능 명세: 코덱 정리와 병렬 송신 안전성

**작성일**: 2026-10-16
**상태**: 명세 검증 완료
**요청**: 버퍼 중복 반환, 정리 실패 후 재실행, 병렬 송신 패킷 공유 문제를 순서대로 해결한다.

## 사용자 시나리오 및 검증

### 사용자 스토리 1 — 부분 실패 후 버퍼 중복 반환 방지 (P1)

운영자는 여러 디코더 버퍼를 반환하다 일부가 실패해도 이미 반환한 버퍼가 다시 반환되지 않기를 원한다.
독립 검증: 첫 버퍼 반환 성공과 다음 버퍼 실패를 주입하고 종료 정리에서 첫 버퍼 반환 횟수가 1회임을 확인한다.
수락 조건: 반환 완료 상태는 즉시 반영되고 미완료 GPU 작업은 기다리며 외부 영상 참조의 수명은 유지된다.

### 사용자 스토리 2 — 최초 정리 오류와 안전한 중단 보존 (P2)

운영자는 정리 실패 때문에 다른 예외로 바뀌거나 같은 위험한 작업을 반복하지 않기를 원한다.
독립 검증: 동기화·버퍼 반환에 실패를 주입해 동일 정리의 재실행이 없고 최초 정리 예외가 전달되는지 확인한다.
수락 조건: 치명적 GPU 오류는 숨기지 않고 종료 경로에 전달한다. 실패한 버퍼 반환과 동기화를 자동 재시도하지 않으며 정상 복구·해제 순서는 유지된다.

### 사용자 스토리 3 — 송신별 패킷 독립성 (P3)

운영자는 동일 압축 패킷을 여러 송신 단계로 보내도 서로의 시간·출력 스트림과 원본을 변경하지 않기를 원한다.
독립 검증: 동일 패킷을 두 송신 단계에서 겹쳐 처리하고 각 출력 스트림과 원본의 메타데이터·데이터가 독립적임을 확인한다.
수락 조건: 기존 시간 보정·재시도·헤더 계약을 유지하며 복사 가능한 부가 데이터와 플래그를 보존한다.

## 요구사항

- **FR-001**: 디코더 버퍼 반환 성공은 즉시 대기 목록과 잠금 상태에 반영하여 다른 반환 실패가 성공 상태를 되돌리지 않는다.
- **FR-002**: 실패한 버퍼 풀의 반환 작업은 이후 정리·외부 참조 해제에서 다시 실행하지 않는다. 실패한 풀로 새 프레임을 처리하지 않는다.
- **FR-003**: 디코더·인코더 동기화 또는 정리 실패 후 동일 실행의 최종 정리가 그 작업을 재실행하지 않고 최초 정리 오류를 보존한다.
- **FR-004**: 치명적인 GPU 오류는 계속 전달하고 기존 정상 복구·종료의 GPU 완료 대기와 자원 수명·해제 순서를 유지한다.
- **FR-005**: 송신 단계는 원본 패킷을 수정하지 않고 송신마다 별도 패킷의 시간과 출력 스트림을 변경한다.
- **FR-006**: 송신 패킷은 압축 내용·PTS·DTS·duration·time_base·키프레임·손상 표시·부가 데이터를 보존한다. 공개 API로 보존할 수 없는 플래그는 명확한 오류로 거부하고 입력 파일 위치는 송신 대상으로 복사하지 않는다.
- **FR-007**: 영상·GPU 버퍼 복사를 추가하지 않는다. 압축 패킷 데이터는 독립성을 보장하는 범위에서 한 번 복사한다.
- **FR-008**: 부분 실패·정리 재진입·동시 송신·실제 파일 송출을 회귀 검증하고 사용자 문서의 입력 변경 및 오류 계약을 갱신한다.

## 성공 기준

- **SC-001**: 부분 실패와 최종 정리를 거쳐 성공한 버퍼의 반환 횟수는 1회이며 실패한 정리의 재시도 횟수는 0회다.
- **SC-002**: 주입한 최초 정리 예외가 보존되고 치명적 GPU 오류가 정상 성공으로 처리되는 경우는 0건이다.
- **SC-003**: 동일 패킷의 병렬 송신에서 각 출력 스트림이 독립적이고 원본 데이터·메타데이터 변경 횟수는 0건이다.
- **SC-004**: 관련 자동 검증과 실제 파일 송출·재디코딩 검증이 통과한다.

## 주요 엔터티

- 버퍼 풀: 잠긴 버퍼·반환 대기 목록·정리 실패 상태를 관리한다.
- 코덱 실행: 정상 또는 정리 실패 상태이며 실패 후 자동 복구를 계속하지 않는다.
- 송신 패킷: 입력과 별도인 헤더·압축 버퍼·부가 데이터를 가지며 해당 송신만 변경한다.

## 경계 조건과 가정

- 반환 실패는 내부에서 실제 반환됐는지 알 수 없으므로 재시도하지 않는다. 실패한 풀은 새 작업에 재사용하지 않는다.
- 정리 실패는 복구 가능한 코덱 처리 오류와 구별한다. GPU 컨텍스트를 강제로 초기화하거나 프로세스를 자동 재시작하는 기능은 범위 밖이다.
- 현재 PyAV 공개 API로 안전한 공유 복사가 보장되지 않으므로 압축 버퍼 독립 복사를 허용한다. 네이티브 비공개 포인터 접근과 새 컴파일 의존성은 추가하지 않는다.
- 정상·오류 처리 중 외부 영상 소유자 수명 계약은 유지한다. 실패한 네이티브 자원이 안전하게 해제됐다고 가장하지 않는다.
