# 기능 명세: 범용 전처리 최적화

작성일: 2026-10-10
상태: 명확화 완료
요청: 기존 TensorRT 전처리의 모든 옵션을 유지하면서 연산과 임시 저장 공간을 줄인다.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 기존 설정으로 효율적인 전처리 (우선순위 P1)

사용자는 별도의 처리 경로 선택 없이 기존 설정으로 동일한 모델 입력을 얻는다.
독립 검증: 기존 계산식과 최적화 결과를 옵션 조합별로 비교한다.

1. RGB/BGR/NV12 입력에 정규화와 크기 조정을 적용하면 출력 형상·자료형·좌표 정보가 유지된다.
2. 설정을 변경하거나 기본값으로 복원하면 새 설정이 즉시 반영된다.
3. 앞 프레임의 출력을 보관해도 다음 프레임 처리로 값이 바뀌지 않는다.

### 경계 조건

크기 변경 없는 입력, 채널별 패딩, 음수·영 배율, 작은 표준편차, 중앙 자르기, 비연속 입력, FP16 출력, 다중 스트림을 검증한다.

## 요구사항

- FR-001: 모든 기존 생성자·설정 옵션과 입력 검증을 유지한다.
- FR-002: 출력 형상·자료형·연속성·변환 정보를 유지하고 입력을 수정하지 않는다.
- FR-003: 기본 정규화의 불필요한 연산과 반복 상수 생성을 줄인다.
- FR-004: 설정 변경 시 기존 상수를 사용하지 않고 출력 저장 공간을 프레임 사이에 공유하지 않는다.
- FR-005: 기존 참조식과의 비교 테스트 및 재현 가능한 성능 측정 도구를 제공한다.

## 성공 기준

- SC-001: FP32 결과는 참조식 대비 rtol=1e-5, atol=1e-5, FP16 결과는 rtol=1e-3, atol=1e-3으로 일치한다.
- SC-002: 기본 정규화에서 평균·표준편차 상수 생성과 뺄셈·나눗셈을 생략한다.
- SC-003: 동일 크기 입력에서 불필요한 크기 조정을 생략한다.
- SC-004: 성능 측정은 준비 실행 후 GPU 시간과 전체 호출 시간을 각각 보고한다. GPU가 없는 환경은 실행 제한을 명시한다.

## 가정과 명확화

기존 라이브러리와 공개 인터페이스를 유지한다. 이번 범위는 범용 구현의 중간 할당·항등 연산 제거이며 신규 CUDA 컴파일 의존성은 추가하지 않는다. 전처리·추론 사이 동기화 변경은 범위 밖이다. 핵심 모호성은 없으며 추가 질문은 필요하지 않다.
