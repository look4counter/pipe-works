# 구현 계획: 범용 전처리 최적화

## 기술 맥락

Python 3.11, PyTorch 2.2.1 CUDA를 유지한다. `src/pipeworks/embedded/tensor_rt_preprocess.py`만 처리 구현을 변경한다. 공용 NV12 변환은 변경하지 않는다.

## 원칙 확인

헌법은 미작성 템플릿이므로 별도 규칙을 도출하지 않는다. 모든 신규 Markdown은 한글로 작성하고 speckit 단계를 순서대로 수행한다.

## 설계

정규화 연산 순서는 기존과 동일하게 유지하여 극단적인 유효 설정에서도 수치 의미를 보존한다. 설정 적용 시 장치별 상수 캐시를 비운다. NV12의 255 배율은 제거하되 리사이즈 전에 적용하던 스케일을 이동하면 반올림이 달라지므로 이번 변경에서는 유지한다.

리사이즈가 이미 독립 저장 공간을 가진 픽셀을 받아 동일 크기인 경우 interpolate를 생략한다. 정규화는 소유한 리사이즈 텐서에 in-place 곱셈·뺄셈·나눗셈으로 적용하고 항등 연산을 생략한다. 패딩·평균·표준편차 상수는 장치와 자료형을 키로 캐시한다. 캐시는 각 실행 스트림에서 사용할 수 있도록 준비 완료 이벤트 대신 최초 생성 시 완료를 기다린다(CPU에서는 대기 없음). 프레임 출력 저장 공간은 캐시하지 않는다.

## 검증

기존식과 독립된 랜덤 입력 참조 비교를 CPU와 GPU에서 실행하고 설정 변경, 출력 독립성, 모든 크기 조정·채널·자료형·레이아웃을 확인한다. 벤치마크는 기존식과 변경식을 동일 입력으로 비교하며 GPU 이벤트 시간과 호출 시간을 보고한다.
