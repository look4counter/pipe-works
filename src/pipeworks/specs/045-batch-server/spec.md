# 기능 명세: 배치 서버 옵션명 변경

작성일: 2026-10-18
기존 명세: 저장소 specs/041-batch-process-alias/spec.md의 별칭 선택 동작을 유지한다.

## 사용자 시나리오와 검증

### 사용자 이야기 1 — 배치 서버 선택 (우선순위: P1)

사용자는 `Pipeline(name, config=path, batch_server="camera-a")`로 서버 별칭을 지정한다.
인수 조건: 기본값 production, 별칭 검증, 직렬화, 원격 전달 및 로컬 라우팅이 기존과 동일하다.
이전 batch_process 인자는 지원하지 않으며 생성 시 TypeError로 거부한다.

## 요구사항

- FR-001: 생성자 인자와 공개 속성 이름을 batch_server로 변경한다.
- FR-002: 기본값 production과 영문자·숫자·밑줄·하이픈 1~64자 규칙 및 예외 종류를 유지한다.
- FR-003: 중앙 연결은 새 속성을 사용하며 내부 server_group 및 CLI는 유지한다.
- FR-004: 예제·현재 사용 문서·기존 테스트 및 관련 명세의 이름을 갱신한다.

## 성공 기준

- SC-001: 기본값, 별칭 검증, 직렬화, 원격 라우팅 검증이 통과한다.
- SC-002: 실행 코드에서 이전 이름을 참조하지 않는다.
- SC-003: 허용 범위 밖의 변경은 검토 및 적용 가능한 패치로 제공한다.

## 경계 조건과 명확화

단순 이름 변경이며 호환 별칭은 추가하지 않는다. 중대한 불명확성은 없어 추가 질문은 0건이다.
현재 쓰기 허용 경로는 src/pipeworks이므로 외부 파일은 직접 변경하지 않고 패치로 준비한다.
FR-004의 실제 원본 파일 반영은 권한 제약이 해소되기 전까지 미완료로 기록한다.
