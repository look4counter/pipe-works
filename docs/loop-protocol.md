# LOOP 개발 프로토콜

SDK 개발은 다음 루프를 반복한다.

저장소 상태 확인
 -> 가장 우선순위가 높은 미완료 작업 선택
 -> 에이전트 어댑터를 통해 구현
 -> 하네스로 검증
 -> 검증 증거 기록
 -> 작업/스펙/결정 문서 갱신
 -> 다음 작업으로 반복

다음 조건이 아니면 루프를 멈추지 않는다.

- 명시적인 사람 승인 단계가 필요한 경우
- 자격 증명이나 외부 비밀값이 필요한 경우
- 운영 환경에 직접 영향을 주는 경우
- 요구사항이나 승인 기준이 서로 충돌하는 경우
- 필요한 검증 증거를 로컬 도구로 만들 수 없는 경우
- 진행 가능한 작업이 더 이상 없는 경우

같은 수정 경로는 최대 세 번까지만 반복한다. 세 번째에도 해결되지 않으면
막힌 원인과 시도한 증거를 기록하고, 다른 진행 가능한 조사로 전환한다.
