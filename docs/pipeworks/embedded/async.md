# Async: 대기를 제한하는 공통 비동기 단계

`Async`는 다른 처리 단계를 별도 작업 스레드에서 실행한다. 기한 안에 완료되면 결과를 원본 컨텍스트에 반영하고, 시간 초과나 오류가 발생하면 원본을 그대로 전달한다. 기본 제한 시간은 5ms이다.

```python
from pipeworks.embedded import Async, YoloDetectBatch

pipeline.step(Async(YoloDetectBatch(model_path), timeout_ms=10))
```

일반 사용자 `Step`도 같은 방식으로 감쌀 수 있다. 공개 가져오기는 `from pipeworks.embedded import Async`를 사용한다. 모듈에서 직접 가져올 때는 `from pipeworks.embedded.async_step import Async`를 사용한다. 구현 파일은 `src/pipeworks/embedded/async_step.py`이다.

## 처리 규칙

- 정상 처리에서는 감싼 단계의 처리 반복자를 유지한다. 지역 카운터와 상태가 매 프레임 초기화되지 않는다.
- 기한 안에 나온 결과로 원본 속성을 갱신하고 같은 원본 객체를 전달한다.
- 이전 요청이 진행 중이면 후속 입력은 복사하거나 제출하지 않고 통과한다. 요청을 쌓지 않는다.
- 시간 초과 후 완료된 결과는 폐기한다. 이미 실행 중인 작업을 강제로 취소하지 않는다.
- 처리 오류나 복사 오류는 로그로 남기고 원본을 전달한다. 처리 오류 뒤 다음 요청에서는 처리 반복자를 다시 시작한다.
- 입력 종료나 조기 종료는 작업 완료를 무한히 기다리지 않는다. 작업자가 완료한 뒤 처리 반복자를 정리한다.
- 같은 인스턴스를 다시 사용해도 이전 작업자가 정리를 마칠 때까지 새 입력은 통과한다. 인스턴스 하나에서 작업자를 중복 실행하지 않는다.

## 설정

```yaml
Async:
  timeout_ms: 10
  step:
    classes: [2]
    confidence: 0.4
    gpu_id: 0
    inference_interval: 3
```

`timeout_ms`는 유한한 0 이상의 숫자이며, 0이면 결과를 기다리지 않는다. 구성에 없으면 생성자 값을 유지한다. `step` 매핑은 감싼 단계의 설정이다. 이 매핑이 없으면 `timeout_ms` 외 항목을 감싼 단계에 직접 전달한다. 감싼 단계의 이름으로 된 최상위 YAML 섹션은 자동 조회하지 않는다.

## 입력 격리와 지원 범위

중첩 가변 데이터는 깊은 복사한다. CPU·GPU 텐서는 복제하고, `frame`의 DLPack 공급자는 복제된 텐서로 전달한다. GPU 복사 완료 전까지 원본을 보관하고 작업자에서 CUDA 이벤트를 확인한다. 입력 복사 시간도 기한에 포함하지만 복사 자체를 강제로 중단하지 않는다.

`cuda_stream`, `video_stream`, `audio_stream`은 읽기 전용 공유 자원이다. 감싼 단계에서 이 자원을 수정하지 않아야 한다. 그 외 복사 불가능한 입력은 로그와 함께 통과한다.

감싼 단계는 입력 하나를 받은 뒤 출력 하나를 내야 한다. 다음 입력을 읽거나 출력하기 전에 해당 입력의 처리를 마쳐야 하며, 출력 후 결과나 입력을 수정하면 안 된다. 소스, 여러 입력을 모으는 집계, 입력당 여러 출력은 지원하지 않는다. 파일 저장이나 네트워크 전송 같은 외부 부작용은 시간 초과로 되돌리지 않는다. 사용자 단계 코드의 자동 핫스왑은 제공하지 않는다.

사용 중 통과한 프레임은 감싼 단계가 보지 않는다. 따라서 내부 `inference_interval` 같은 카운터는 실제 제출된 입력을 기준으로 증가한다.

## 기존 모델 단계와 조합

`YoloDetect`는 동기로 실행하며 모델 동명 YAML의 제한 시간을 읽지 않는다. `Async(YoloDetect(model_path), timeout_ms=5)`로 감싸면 공통 래퍼가 비동기 실행·시간 제한·오류 통과를 적용한다. 실패하거나 시간 초과한 요청은 원본을 그대로 전달하므로 원본에 `detections`가 없었다면 이후에도 없을 수 있다. 결과 확인에는 `getattr(context, "detections", None)`을 사용할 수 있다.

`TensorRTInference`는 자체 비동기·시간 제한 처리를 유지하므로 `Async`로 감싸면 두 제한이 함께 적용된다. 내부 시간 초과를 바깥 `Async`가 늘려 주지는 않는다.

`YoloDetectBatch`는 공유 배치 결과를 기다리는 동안 바깥 `Async`가 원본을 통과시킬 수 있다. 모델 설정의 `timeout`은 배치를 모으는 시간이고, `Async.timeout_ms`는 요청 결과를 기다리는 시간이다. GPU 입력 복사는 각 단계에서 수행하므로 추가 복사 비용이 있다. `YoloDetect(batch=True)` 옵션은 이번 변경에 포함하지 않는다.
