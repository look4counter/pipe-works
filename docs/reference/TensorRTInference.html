설정 파라미터

파라미터 기본값 설정 위치 설명
model_path 필수 생성자 전용 모델 파일 경로입니다.
batch False 생성자 전용 불리언입니다. True이면 공유 배치 추론 경로를 사용합니다. YAML로 변경하지 않습니다.
gpu_id 0 생성자 / YAML 추론할 GPU 번호입니다. 0 이상의 정수이며 입력 텐서·스트림의 GPU와 일치해야 합니다.
inference_interval_frame 1 생성자 / YAML 추론을 수행할 프레임 간격입니다. 1 이상의 정수이며 건너뛴 프레임 결과는 None입니다.
id None 생성자 / YAML 모델 식별자입니다. 비어 있지 않은 문자열을 사용하며 None이면 모델 파일명(확장자 포함)을 사용합니다.
profile_index 0 생성자 / YAML TensorRT 최적화 프로파일 번호입니다. 0 이상의 정수이며 엔진의 프로파일 범위 안에 있어야 합니다.
