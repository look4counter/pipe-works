입력과 출력은 PipelineContext의 변수 기준입니다. 선택 항목은 생략할 수 있으며, 별도 안내가 없으면 출력에 명시하지 않은 기존 변수도 유지합니다. 생성자·YAML 설정과 내부 관리 변수는 목록에서 제외했습니다.

내장 Step

TensorRTInference

TensorRT 엔진을 실행하여 입력 텐서에 대한 추론 결과를 생성합니다.

설정 파라미터

파라미터기본값설정 위치설명
model_path필수생성자 전용모델 파일 경로입니다.
batchFalse생성자 전용불리언입니다. True이면 공유 배치 추론 경로를 사용합니다. YAML로 변경하지 않습니다.
gpu_id0생성자 / YAML추론할 GPU 번호입니다. 0 이상의 정수이며 입력 텐서·스트림의 GPU와 일치해야 합니다.
inference_interval_frame1생성자 / YAML추론을 수행할 프레임 간격입니다. 1 이상의 정수이며 건너뛴 프레임 결과는 None입니다.
idNone생성자 / YAML모델 식별자입니다. 비어 있지 않은 문자열을 사용하며 None이면 모델 파일명(확장자 포함)을 사용합니다.
profile_index0생성자 / YAMLTensorRT 최적화 프로파일 번호입니다. 0 이상의 정수이며 엔진의 프로파일 범위 안에 있어야 합니다.

기본값은 인자를 생략한 생성자 기준입니다. 생성자에서 지정한 값이 기본 설정이 되며, YAML 설정이 있으면 해당 항목을 덮어씁니다.

inference_interval은 지원하지 않습니다. 프레임 단위의 inference_interval_frame을 사용합니다.

요구하는 Input 변수

변수 설명
model_input 설정한 GPU의 텐서 또는 엔진 입력 이름을 키로 하는 텐서 사전입니다. 형상과 자료형은 엔진과 일치해야 합니다.
model_cuda_stream 선택 항목입니다. 입력 텐서를 생산한 CUDA 스트림입니다.
cuda_stream 선택 항목입니다. 모델 스트림이 없을 때 입력 준비 스트림으로 사용하며, 없으면 현재 CUDA 스트림을 사용합니다.

제공하는 Output 변수

변수 설명
model_output 엔진 출력 이름을 키로 하는 GPU 텐서 사전입니다. 추론을 건너뛰면 None입니다.
model_id 설정한 모델 ID입니다. 후처리에서 검출 결과의 키로 사용합니다.

기존 입력 변수는 유지합니다.
