내장 Step

NvidiaDecode

NVIDIA GPU에서 압축 패킷을 디코딩하고 프레임을 전달합니다.

설정 파라미터

파라미터기본값설정 위치설명
gpu_id0생성자 / YAML디코딩에 사용할 GPU 장치 번호입니다.

기본값은 인자를 생략한 생성자 기준입니다. 생성자에서 지정한 값이 기본 설정이 되며, YAML 설정이 있으면 해당 항목을 덮어씁니다.

요구하는 Input 변수

변수 설명
packet 디코딩할 압축 패킷입니다.
video_stream 입력 영상의 코덱과 해상도 정보입니다.

제공하는 Output 변수

변수 설명
frame GPU에 저장된 디코딩 프레임입니다.
pixel_format 디코더가 반환하는 실제 픽셀 형식입니다.
cuda_stream 후속 프레임 처리를 위한 CUDA 스트림입니다.
video_stream 입력 비디오 스트림 정보입니다.
decoded_at 디코딩 결과를 큐에 넣은 시각(perf_counter 기준, 초)입니다.
processing_started_at 큐에서 꺼내 후속 처리를 시작한 시각입니다.
decode_dropped_frames 디코딩 큐에서 폐기한 프레임의 누적 개수입니다.

새 컨텍스트를 생성합니다. 큐 용량은 30개이며 가득 차면 오래된 프레임을 폐기합니다.
