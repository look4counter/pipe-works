BoxOverlay

입력과 출력은 PipelineContext의 변수 기준입니다. 선택 항목은 생략할 수 있으며, 별도 안내가 없으면 출력에 명시하지 않은 기존 변수도 유지합니다. 생성자·YAML 설정과 내부 관리 변수는 목록에서 제외했습니다.

예제 Step

BoxOverlay

GPU의 NV12 영상에 검출 상자 테두리를 그립니다.

설정 파라미터

파라미터기본값설정 위치설명
line_width2YAML / 클래스 기본값상자 테두리 두께(픽셀)입니다. 1 이상의 정수이며 불리언은 허용하지 않습니다.
line_color"#00ff00"YAML / 클래스 기본값테두리 색상입니다. #RRGGBB 형식의 문자열을 사용합니다.
keep_previousTrueYAML / 클래스 기본값새 결과가 없을 때 이전 상자를 유지할지 지정하는 불리언입니다. 빈 상자 결과는 이전 상자를 지웁니다.
idNoneYAML / 클래스 기본값표시할 모델 ID입니다. 비어 있지 않은 문자열 또는 None이며 None이면 모든 모델 결과를 표시합니다.

요구하는 Input 변수

변수 설명
frame CUDA 스트림과 같은 GPU의 uint8 NV12 프레임입니다.
pixel_format NV12여야 합니다.
video_stream.codec_context.width 영상 너비이며 양의 짝수여야 합니다.
video_stream.codec_context.height 영상 높이이며 양의 짝수여야 합니다.
cuda_stream 프레임과 같은 GPU의 CUDA 스트림입니다.
detections 선택 항목입니다. 모델 ID별 검출 결과이며 boxes.xyxy는 같은 GPU의 N×4 텐서입니다. id=None이면 단일 YOLO 결과도 허용합니다.

제공하는 Output 변수

변수 설명
frame 원본 저장 공간에 검출 상자 테두리를 그린 프레임입니다.

같은 컨텍스트를 전달합니다. 새 검출 결과가 없으면 keep_previous 설정에 따라 이전 상자를 사용합니다.
