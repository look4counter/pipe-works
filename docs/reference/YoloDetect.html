내장 Step

YoloDetect

NV12 영상을 전처리하고 YOLO 모델로 객체를 검출합니다.

설정 파라미터

파라미터기본값설정 위치설명
model_path필수생성자 전용모델 파일 경로입니다.
batchFalse생성자 전용불리언입니다. True이면 공유 배치 추론 경로를 사용합니다. YAML로 변경하지 않습니다.
classesNone생성자 / YAML검출할 클래스 ID 목록입니다. 0 이상의 정수 목록이며 None이면 모든 클래스를 대상으로 합니다.
confidence0.25생성자 / YAML검출 신뢰도 임계값입니다. 0보다 크고 1 이하인 숫자입니다.
gpu_id0생성자 / YAML추론할 GPU 번호입니다. 0 이상의 정수이며 입력 텐서·스트림의 GPU와 일치해야 합니다.
inference_interval_frame1생성자 / YAML추론을 수행할 프레임 간격입니다. 1 이상의 정수이며 건너뛴 프레임 결과는 None입니다.
idNone생성자 / YAML모델 식별자입니다. 비어 있지 않은 문자열을 사용하며 None이면 모델 파일명(확장자 포함)을 사용합니다.

기본값은 인자를 생략한 생성자 기준입니다. 생성자에서 지정한 값이 기본 설정이 되며, YAML 설정이 있으면 해당 항목을 덮어씁니다.

inference_interval은 지원하지 않습니다. 프레임 단위의 inference_interval_frame을 사용합니다.

요구하는 Input 변수

변수 설명
frame 설정한 GPU의 uint8 NV12 프레임입니다.
pixel_format NV12여야 합니다.
video_stream.codec_context.width 영상 너비이며 양의 짝수여야 합니다.
video_stream.codec_context.height 영상 높이이며 양의 짝수여야 합니다.
cuda_stream 프레임과 같은 GPU의 CUDA 스트림입니다.
detections 선택 항목입니다. 기존 모델 결과를 보존할 모델 ID별 사전입니다.

제공하는 Output 변수

변수 설명
detections[id] 설정한 모델 ID의 YOLO 검출 결과입니다. 추론을 건너뛴 프레임은 None입니다.

다른 컨텍스트 변수는 유지합니다. 결과의 boxes는 상자 좌표·신뢰도·클래스를, names는 클래스 이름을 제공합니다.
