TensorRTPostProcess

입력과 출력은 PipelineContext의 변수 기준입니다. 선택 항목은 생략할 수 있으며, 별도 안내가 없으면 출력에 명시하지 않은 기존 변수도 유지합니다. 생성자·YAML 설정과 내부 관리 변수는 목록에서 제외했습니다.

예제 Step

TensorRTPostProcess

YOLO11 TensorRT 출력을 필터링하고 NMS를 수행해 원본 좌표의 검출 결과를 만듭니다.

설정 파라미터

파라미터기본값설정 위치설명
confidence0.25YAML / 클래스 기본값검출 신뢰도 임계값입니다. 유한한 0~1 숫자입니다.
iou0.7YAML / 클래스 기본값NMS의 IoU 임계값입니다. 유한한 0~1 숫자입니다.
classes[2]YAML / 클래스 기본값검출할 COCO 클래스 ID 목록입니다. 0~79 정수를 사용하며 기본값은 자동차입니다. None이면 모든 클래스를 허용합니다.
max_det300YAML / 클래스 기본값NMS 후 유지할 최대 검출 개수입니다. 1 이상의 정수입니다.
output_name"output0"YAML / 클래스 기본값후처리에 사용할 엔진 출력 텐서의 이름입니다. 비어 있지 않은 문자열입니다.

요구하는 Input 변수

변수 설명
model_output 추론 결과 사전 또는 None입니다. 결과가 있으면 선택한 출력은 같은 GPU의 FP32 (1, 84, N) 텐서여야 합니다.
model_id 결과가 있을 때 필요한 모델 ID입니다.
tensor_rt_transform 결과가 있을 때 필요한 좌표 복원 정보입니다.
cuda_stream GPU 장치 확인과 기본 실행 스트림에 사용합니다.
model_cuda_stream 선택 항목입니다. 모델 처리 CUDA 스트림입니다.
detections 선택 항목입니다. 기존 모델 결과를 보존할 사전입니다.

제공하는 Output 변수

변수 설명
detections[model_id] boxes·names·orig_shape를 가진 결과입니다. 추론을 건너뛰면 해당 ID의 값은 None입니다.

처리 후 model_input, model_output, tensor_rt_transform, model_cuda_stream, model_id를 컨텍스트에서 제거합니다.
