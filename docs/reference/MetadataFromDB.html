MetadataFromDB

입력과 출력은 PipelineContext의 변수 기준입니다. 선택 항목은 생략할 수 있으며, 별도 안내가 없으면 출력에 명시하지 않은 기존 변수도 유지합니다. 생성자·YAML 설정과 내부 관리 변수는 목록에서 제외했습니다.

예제 Step

MetadataFromDB

백그라운드에서 3초마다 카운트를 갱신하는 구조를 보여 줍니다.

설정 파라미터

설정 파라미터가 없습니다. 전달된 설정은 사용하지 않습니다.

요구하는 Input 변수

추가로 요구하는 입력 변수는 없습니다.

제공하는 Output 변수

변수 설명
기존 컨텍스트 변수 입력 컨텍스트를 그대로 전달합니다. 새 변수는 추가하지 않습니다.

실제 DB 연결은 없습니다. metadata.count는 Step 인스턴스 내부 값이며 출력 컨텍스트에 추가되지 않습니다.
