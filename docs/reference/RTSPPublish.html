입력과 출력은 PipelineContext의 변수 기준입니다. 선택 항목은 생략할 수 있으며, 별도 안내가 없으면 출력에 명시하지 않은 기존 변수도 유지합니다. 생성자·YAML 설정과 내부 관리 변수는 목록에서 제외했습니다.

내장 Step

RTSPPublish

압축 비디오 패킷을 RTSP 서버로 송출합니다.

설정 파라미터

파라미터기본값설정 위치설명
url필수생성자 전용송출할 RTSP 주소입니다. YAML로 변경하지 않습니다.
reconnectTrue생성자 / YAML연결 실패·스트림 종료 시 재연결 여부입니다. 불리언을 사용합니다.
reconnect_interval_ms3000생성자 / YAML재연결 대기 시간입니다. 밀리초 단위의 유한한 0 이상 숫자입니다.
transport"tcp"생성자 / YAMLRTSP 전송 방식입니다. "tcp" 또는 "udp"를 사용합니다.
timeout_ms5000생성자 / YAML연결·읽기 또는 송출 작업의 제한 시간입니다. 밀리초 단위의 유한한 0 이상 숫자입니다.
packet_size1452생성자 / YAML송출 패킷 크기(바이트)입니다. 양수 값을 사용합니다.

기본값은 인자를 생략한 생성자 기준입니다. 생성자에서 지정한 값이 기본 설정이 되며, YAML 설정이 있으면 해당 항목을 덮어씁니다.

reconnect_interval과 timeout은 지원하지 않습니다. 밀리초 단위의 reconnect_interval_ms와 timeout_ms를 사용합니다.

요구하는 Input 변수

변수 설명
packet 송출할 압축 패킷입니다. 시간 기준은 패킷 또는 스트림에서 얻습니다.
video_stream 출력 스트림을 구성할 코덱·해상도·시간 기준 정보입니다.

제공하는 Output 변수

후속 컨텍스트를 출력하지 않습니다.

종단 Step입니다. 패킷의 시간 정보와 stream을 보정하며 후속 컨텍스트는 출력하지 않습니다.
