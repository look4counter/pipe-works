내장 Step

CudaAsync

감싼 Step들을 작업 스레드에서 실행하고 제한 시간 내 결과를 반영합니다.

설정 파라미터

파라미터기본값설정 위치설명
steps필수생성자 전용하나 이상의 Step을 위치 인자로 전달합니다. 내부 Step의 설정은 각 클래스의 최상위 YAML 섹션으로 지정합니다.
timeout_ms5생성자 / YAML입력별 결과를 기다리는 제한 시간입니다. 밀리초 단위의 유한한 0 이상 숫자입니다. CudaAsync 자체의 YAML 옵션은 이 항목만 허용합니다.

기본값은 인자를 생략한 생성자 기준입니다. 생성자에서 지정한 값이 기본 설정이 되며, YAML 설정이 있으면 해당 항목을 덮어씁니다.

요구하는 Input 변수

변수 설명
감싼 Step의 입력 변수 내부 Step들이 요구하는 모든 컨텍스트 변수가 필요합니다.
cuda_stream 선택 항목입니다. 입력 GPU 작업과 작업 스레드 사이의 실행 순서를 맞춥니다.

제공하는 Output 변수

변수 설명
감싼 Step의 출력 변수 제한 시간 안에 완료한 내부 처리 결과의 컨텍스트 변수를 반영합니다.

고정된 출력 변수는 없습니다. 내부 Step은 입력 하나마다 출력 하나를 제공해야 합니다. 시간 초과 시 원본 사용이 끝났으면 원본을 전달하고, 아직 사용 중이면 해당 프레임을 폐기합니다.
