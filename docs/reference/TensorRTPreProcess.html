TensorRTPreProcess

입력과 출력은 PipelineContext의 변수 기준입니다. 선택 항목은 생략할 수 있으며, 별도 안내가 없으면 출력에 명시하지 않은 기존 변수도 유지합니다. 생성자·YAML 설정과 내부 관리 변수는 목록에서 제외했습니다.

예제 Step

TensorRTPreProcess

GPU 영상을 변환·리사이즈·정규화하여 모델 입력 텐서를 생성합니다.

설정 파라미터

파라미터기본값설정 위치설명
size[640, 640]생성자 / YAML목표 크기 [높이, 너비]입니다. 두 값 모두 양의 정수이며 모델 입력 조건과 맞춰야 합니다.
resize_mode"letterbox"생성자 / YAML"letterbox"는 비율 유지 후 패딩, "stretch"는 지정 크기로 변형, "resize_center_crop"은 비율 유지 확대 후 중앙 크롭입니다.
autoFalse생성자 / YAMLletterbox 패딩을 stride의 나머지만큼으로 줄이는 불리언입니다. True는 letterbox에서만 허용하며 최종 크기가 size보다 작아질 수 있습니다.
stride32생성자 / YAMLauto=True인 letterbox에서 패딩을 줄일 기준입니다. 양의 정수입니다.
scaleupTrue생성자 / YAMLletterbox에서 작은 이미지를 확대할지 지정합니다. False이면 배율을 최대 1로 제한합니다.
centerTrue생성자 / YAMLletterbox 패딩을 양쪽으로 나눌지 지정합니다. False이면 영상을 왼쪽 위에 배치합니다. 중앙 크롭에는 적용하지 않습니다.
padding_value114생성자 / YAMLletterbox의 채움 픽셀 값입니다. 0~255 숫자 하나 또는 채널별 숫자 세 개를 사용합니다.
crop_sizeNone생성자 / YAMLresize_center_crop에서 최종 [높이, 너비]입니다. 양의 정수 두 개이며 각 값이 size 이하여야 합니다. None이면 size를 사용합니다.
color_order"rgb"생성자 / YAML출력 색상 채널 순서입니다. "rgb" 또는 "bgr"입니다.
scale1 / 255생성자 / YAML픽셀 값에 곱하는 유한한 숫자입니다. 기본값으로 0~255 픽셀을 0~1로 바꿉니다.
mean[0, 0, 0]생성자 / YAMLscale 적용 후 빼는 채널별 평균입니다. 유한한 숫자 세 개를 사용합니다.
std[1, 1, 1]생성자 / YAML평균을 뺀 후 나누는 채널별 표준편차입니다. 양의 유한한 숫자 세 개를 사용합니다. 출력은 (픽셀 × scale − mean) / std입니다.
dtype"float32"생성자 / YAML출력 텐서 자료형입니다. "float32" 또는 "float16"입니다.
layout"nchw"생성자 / YAML출력 배치 텐서 축 순서입니다. "nchw" 또는 "nhwc"이며 배치 크기는 1입니다.
input_nameNone생성자 / YAML엔진 입력 이름입니다. 비어 있지 않은 문자열이면 model_input을 해당 이름의 사전으로 만들고, None이면 텐서 자체를 제공합니다.

기본값은 인자를 생략한 생성자 기준입니다. 생성자에서 지정한 값이 기본 설정이 되며, YAML 설정이 있으면 해당 항목을 덮어씁니다.

요구하는 Input 변수

변수 설명
frame GPU의 uint8 NV12 또는 HWC 3채널 RGB/BGR 프레임입니다.
pixel_format NV12, RGB 또는 BGR입니다.
video_stream.codec_context.width NV12 입력에서 필요한 양의 짝수 너비입니다.
video_stream.codec_context.height NV12 입력에서 필요한 양의 짝수 높이입니다.
cuda_stream 선택 항목입니다. 프레임 생산 스트림이며 생략하면 해당 GPU의 현재 스트림을 사용합니다.

제공하는 Output 변수

변수 설명
model_input 설정한 크기·자료형·레이아웃의 배치 1 텐서입니다. input_name이 있으면 이름을 키로 하는 사전입니다.
tensor_rt_transform 원본 크기와 리사이즈·패딩·크롭 정보를 가진 ImageTransform입니다.
model_cuda_stream 전처리 텐서를 생산한 모델 CUDA 스트림입니다.

다른 컨텍스트 변수는 유지합니다.
