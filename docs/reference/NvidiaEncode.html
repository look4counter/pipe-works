내장 Step

NvidiaEncode

GPU 프레임을 압축 비디오 패킷으로 인코딩합니다.

설정 파라미터

파라미터기본값설정 위치설명
gpu_id0생성자 / YAML인코딩에 사용할 GPU 장치 번호입니다.
fps30생성자 / YAML출력 프레임률입니다. 양수여야 하며 GOP·IDR 주기와 패킷 시간 기준에도 사용합니다. 현재 패킷 시간 기준 계산은 정수 fps를 전제로 합니다.

기본값은 인자를 생략한 생성자 기준입니다. 생성자에서 지정한 값이 기본 설정이 되며, YAML 설정이 있으면 해당 항목을 덮어씁니다.

요구하는 Input 변수

변수 설명
frame 인코더에 전달할 GPU 프레임입니다.
pixel_format 프레임의 픽셀 형식입니다.
video_stream 코덱과 영상 너비·높이 정보입니다.
cuda_stream 인코딩 작업에 사용할 CUDA 스트림입니다.
processing_started_at 선택 항목입니다. 프레임 처리 시간 집계에 사용합니다.

제공하는 Output 변수

변수 설명
packet PTS·DTS·time_base·duration이 설정된 인코딩 패킷입니다.
video_stream 입력 비디오 스트림 정보입니다.

새 컨텍스트를 생성하므로 다른 입력 변수는 전달하지 않습니다. 프레임과 패킷의 개수는 일대일이 아닐 수 있습니다.
