자동 복구

복구 가능한 인코더 생성·인코딩 오류가 발생하면 오류 프레임과 인코더를 버리고 최소 1초 후 최신 입력으로 재생성을 시도합니다. 대기 중 입력은 버리며 연속 실패에도 사용자 개입 없이 재시도합니다.

입력 스트림·코덱·해상도·픽셀 형식·CUDA 스트림 변경을 감지합니다. H.264/HEVC 영상 헤더와 시작 프레임을 새 세션에서 제공하며 PTS/DTS와 시간 기준은 유지합니다. 복구 중에는 영상이 잠시 멈추거나 프레임이 누락될 수 있습니다.

복구 가능한 종료 오류의 잔여 패킷은 버립니다. 설정·지원 불가·입력 소스·후속 처리 오류는 전달하며 네이티브 프로세스 충돌은 복구 대상이 아닙니다.

설정 파라미터

파라미터 기본값 설정 위치 설명
gpu_id 0 생성자 / YAML 인코딩에 사용할 GPU 장치 번호입니다.
fps 30 생성자 / YAML 출력 프레임률입니다. 양수여야 하며 GOP·IDR 주기와 패킷 시간 기준에도 기본 모드에서 사용합니다. 기본 모드 시간 기준 계산은 정수 fps를 전제로 합니다.
preserve_timestamps False 생성자 / YAML True이면 입력 컨텍스트의 pts·time_base·선택적 duration을 보존합니다. DTS는 PTS와 같습니다. time_base 생략 시 video_stream.time_base를 사용합니다. 원본 시간이 없거나 유효하지 않으면 입력을 폐기합니다. 수정 PyNvVideoCodec wheel에서는 NvidiaDecode가 잠금 API의 PTS를 전달합니다. 공식 wheel에서는 pts가 None이므로 보존 모드 입력을 폐기합니다. fps는 인코더 설정에 계속 사용하며 RTSPPublish는 중복·역행 DTS 패킷을 보정하지 않고 건너뜁니다.
