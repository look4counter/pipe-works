내장 Step

RTSPSource

RTSP 영상 스트림에서 압축 패킷을 수신합니다.

설정 파라미터

파라미터 기본값 설정 위치 설명
url 필수 생성자 전용 수신할 RTSP 주소입니다.
reconnect True 생성자 / YAML 연결 실패·스트림 종료 시 재연결 여부입니다.
reconnect_interval_ms 3000 생성자 / YAML 재연결 대기 시간입니다.
transport "tcp" 생성자 / YAML RTSP 전송 방식입니다. "tcp" 또는 "udp"를 사용합니다.
timeout_ms 5000 생성자 / YAML 연결·읽기 또는 송출 작업의 제한 시간입니다.

reconnect_interval과 timeout은 지원하지 않습니다. 밀리초 단위의 reconnect_interval_ms와 timeout_ms를 사용합니다.

요구하는 Input 변수

추가로 요구하는 입력 변수는 없습니다.

제공하는 Output 변수

변수 설명
packet 수신한 비디오 압축 패킷(av.Packet)입니다.
video_stream 패킷의 코덱·해상도·시간 기준을 가진 비디오 스트림입니다.

소스 Step으로 이전 단계의 입력을 사용하지 않습니다.
